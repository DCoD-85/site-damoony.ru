# 🏛 Поток данных: от URL до HTML

Каждый запрос к сайту проходит строго определенный путь. Понимание этого пути критично для отладки и расширения системы.

## Визуальная схема

Браузер делает запрос GET /ru-ru/blog/post-1.
Дальше запрос проходит следующие этапы:

1. www/index.php
   Проверяет конфиги, хост, запускает сессию, подключает движок.

2. engine/main.php
   Оркестратор. Инициализирует настройки, домен, аллиас и базовые классы.
   Передает управление роутеру.

3. engine/tree.php
   Роутер. Ищет правила в .rules.json на каждом уровне вложенности:
   - algoritm.rules.json
   - lang/algoritm_lang.rules.json
   - lang/blog/algoritm_lang_blog.rules.json
   Находит нужный PHP-класс и вызывает его.

4. app/.../algoritm_lang_blog.php
   Логика страницы. Собирает контент через Visuo.
   Добавляет результат в глобальный блок center.

5. visuo/visuorelease.php
   Рендеринг. Собирает финальный HTML (html, head, body)
   и отдает его в браузер.

## Пошаговый разбор

### 1. Точка входа (www/index.php)
*   Проверяет валидность домена по site.config (защита от Bad Host).
*   Настраивает безопасные cookie (SSO-ready для поддоменов).
*   Запускает engine/main.php.

### 2. Оркестратор (engine/main.php)
*   Метод init(): подключает базовые классы, инициализирует db, user, library, language.
*   Метод logic():
    *   Читает engine.config и site.config.
    *   Определяет REAL-домен (например, www.damoony2.ru -> damoony.ru).
    *   Определяет текущий АЛЛИАС (например, www).
    *   Если домен или аллиас выключен — показывает заглушку.
    *   Инициализирует глобальные блоки (alliasglobal), схемы (alliasscheme) и провайдеры данных (dataprovider).
    *   Передает управление роутеру tree.php.

### 3. Маршрутизация (engine/tree.php)
*   Разбирает URL на сегменты (например, ['ru-ru', 'blog', 'post-1']).
*   Начинает обход с корня algoritm/ и ищет algoritm.rules.json.
*   На каждом уровне проверяет available (совпал ли сегмент) и auth (если требуется авторизация, а гость стучится — отдает errors/403.php).
*   Находит конечный PHP-класс (например, algoritm_lang_blog.php) и вызывает метод default().

### 4. Логика страницы (app/.../algoritm_...php)
*   Класс наследуется от algoritm_.
*   Метод default() (или guest()/logged()) собирает контент.
*   Контент собирается исключительно через visuotag и visuoel (без прямого echo).
*   Собранные блоки внедряются в глобальные обертки (например, $this->main->alliasglobal->center).

### 5. Рендеринг (visuo/visuorelease.php)
*   Собирает воедино html, head (с мета-тегами и CSS) и body.
*   Применяет схемы (Layout), если они включены.
*   Отдает итоговый HTML-код в браузер.
