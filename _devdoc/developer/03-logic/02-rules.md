# 💻 Логика: Правила маршрутизации (.rules.json)

Файлы `.rules.json` — это сердце нового роутера `tree.php`. Они лежат в каждой папке с логикой страниц и описывают, какие URL разрешены на этом уровне и кому они доступны.

## Структура файла

Каждый файл правил содержит всего два ключа:

```json
{
    "available": ["index", "about", "[a-z0-9-]+|slug"],
    "auth": false
}
```

*   **`available`** (массив строк) — список разрешенных сегментов URL.
*   **`auth`** (boolean) — требуется ли авторизация для доступа к этой странице и всем её дочерним элементам.

## Синтаксис ключа `available`

В массиве `available` можно использовать 4 типа правил:

### 1. Пустая строка `""`
Срабатывает, когда URL-сегмент пуст (пользователь зашел на текущий уровень без продолжения).
Вызывает метод `default()` у текущего PHP-класса.

*Пример:*
```json
"available": [""]
```
Пользователь заходит на `/ru-ru/`. Сработает `algoritm_lang.php` -> `default()`.

### 2. Точное совпадение `"index"`
Срабатывает, если сегмент URL в точности совпадает со строкой. Роутер ищет дочернюю папку с таким же именем и класс внутри нее.

*Пример:*
```json
"available": ["index", "about"]
```
Пользователь заходит на `/ru-ru/index`. Роутер ищет папку `index/` и класс `algoritm_lang_index.php`.

### 3. Перенаправление с пустого URL `"|target"`
Если URL пуст, но вы хотите перенаправить пользователя в дочернюю папку (не вызывая `default()` текущего класса).

*Пример:*
```json
"available": ["|list"]
```
Пользователь заходит на `/ru-ru/blog/`. Роутер перейдет в папку `list/` и вызовет класс `algoritm_lang_blog_list.php`.

### 4. Регулярное выражение `"pattern|param_name"`
Самый мощный инструмент. Позволяет обрабатывать динамические URL (slug, ID и т.д.).
Формат: строка `regex` + разделитель `|` + имя параметра.

*Пример:*
```json
"available": ["[a-z0-9-]+|slug"]
```
Пользователь заходит на `/ru-ru/blog/my-first-post`.
1. Роутер проверяет `my-first-post` по регулярке `[a-z0-9-]+` (совпадает).
2. Переходит в папку `slug/`.
3. Записывает значение в параметр: `$this->args['slug'] = 'my-first-post'`.
4. Вызывает `algoritm_lang_blog_slug.php`.

## Ключ `auth` (Авторизация)
Если `auth` равно `true`, роутер `tree.php` проверяет статус пользователя **до того**, как загрузит PHP-класс страницы.
*   Если пользователь — гость, роутер прерывает работу и отдает `errors/403.php` (Доступ запрещён).
*   Если пользователь авторизован — роутер загружает класс и вызывает его метод.

## Пример полной иерархии

**1. Корень (`algoritm/algoritm.rules.json`)**
```json
{
    "available": ["[a-z]{2}-[a-z]{2}|lang"],
    "auth": false
}
```

**2. Уровень языка (`algoritm/lang/algoritm_lang.rules.json`)**
```json
{
    "available": ["index", "about", "blog"],
    "auth": false
}
```

**3. Уровень блога (`algoritm/lang/blog/algoritm_lang_blog.rules.json`)**
```json
{
    "available": ["|list", "[a-z0-9-]+|slug"],
    "auth": false
}
```

**4. Уровень закрытого профиля (`algoritm/lang/profile/algoritm_lang_profile.rules.json`)**
```json
{
    "available": [],
    "auth": true
}
```
