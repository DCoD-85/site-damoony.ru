# 💻 Ядро: Хелперы (Paths, Config, Fs, Json)

В папке `corescripts/_lib/` лежат базовые классы для работы с файловой системой. Их использование строго обязательно (см. Железные правила проекта). Прямое использование `file_put_contents` или хардкод путей запрещены.

## 1. Fs (Файловая система)
Класс для безопасной работы с файлами и папками.

**Главные методы:**
*   `Fs::writeAtomic($path, $content)` — атомарная запись файла. Сначала пишет во временный файл, затем переименовывает. Если в процессе произойдет сбой (например, отключат питание), старый файл останется целым.
*   `Fs::mkdir($path)` — рекурсивное создание директории (если ее нет).
*   `Fs::rmrf($path)` — рекурсивное удаление папки со всем содержимым.
*   `Fs::rel($absolute_path)` — превращает абсолютный путь в относительный (удобно для вывода в логах или интерфейсе).

## 2. Json (Работа с JSON)
Класс для чтения и записи JSON-файлов. Гарантирует правильную кодировку (UTF-8, без экранирования слэшей) и отступы табами.

**Главные методы:**
*   `Json::read($path, $default)` — читает файл и возвращает массив. Если файла нет или он битый, вернет `$default`.
*   `Json::writeAtomic($path, $data)` — безопасно записывает массив в JSON-файл.
*   `Json::encode($data)` / `Json::decode($json)` — конвертация массива в строку и обратно.

## 3. Config (Управление конфигами)
Класс-обертка для `site.config` и `engine.config`. Позволяет читать и изменять настройки по ключам (через точку или массив).

**Чтение:**
```php
$cfg = new Config( Paths::config() );
$domain = $cfg->get( 'domains_real.damoony.ru' );
$settings = $cfg->getKeys( [ 'fillers', 'damoony.ru', 'www' ] );
```

**Запись (Безопасная мутация):**
Никогда не используйте `$cfg->save()` напрямую, если работаете с конфигом в рантайме (например, из админки). Это может привести к потере данных, если два процесса запишут файл одновременно.

Используйте `Config::mutate()`:
```php
Config::mutate( Paths::config(), function ( Config $cfg ) {
    $cfg->setKeys( [ 'domains_available', 'damoony.ru' ], false );
} );
```
Этот метод блокирует файл (`.lock`), делает бэкап (`.bak`), применяет изменения и атомарно сохраняет.

## 4. Paths (Пути)
Единая точка доступа к путям проекта. Избавляет от хардкода вроде `__DIR__ . '/../../app'`.

**Основные методы:**
*   `Paths::project()` — абсолютный путь к корню проекта.
*   `Paths::config()` — путь к `site.config`.
*   `Paths::engine()` — путь к `engine.config`.
*   `Paths::domain('damoony2.ru')` — путь к папке домена (автоматически маппит алиас на реальный домен `damoony.ru`).
*   `Paths::algoritm('damoony.ru', 'www')` — путь к папке `algoritm/` конкретного аллиаса.
*   `Paths::logic()` — имя текущего движка (например, `alpha.0.0`).
