# Задачи: Инфраструктура и Кеширование

## 1. Кеширование роутера (Tree Cache)
**Проблема:** `tree.php` при каждом запросе читает `.rules.json` с диска. На высоких нагрузках это упирается в I/O.
**Решение:** Внедрить кеширование дерева правил в память (APCu или Redis) с инвалидацией при изменении конфигов.

## 2. Разделение Git и Админки (Environment Split)
**Проблема:** Админка пишет напрямую в файлы, что может вызвать конфликты при деплое через Git.
**Решение:** Разделить `config` и `storage` (пользовательские данные). На проде админка должна писать только в БД или в `storage/`, который в `.gitignore`.

## 3. Оптимизация CRUD (Решение N+1)
**Проблема:** В `ResourceController` при выводе списка записей с типом `relation` выполняется запрос в БД на каждую строку.
**Решение:** Внедрить Eager Loading. Сначала собирать уникальные ID связей, делать один запрос `WHERE id IN (...)`, а затем мапить результаты в памяти.
