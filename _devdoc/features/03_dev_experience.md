# Задачи: Разработка и Экосистема

## 1. Изоляция Visuo и Developer Experience
**Проблема:** Высокий порог входа для верстальщиков (Vendor Lock-in). Нужно учить `visuotag`.
**Решение:** Создать "адаптер" для нативных шаблонов (Twig/Blade) или сделать так, чтобы `visuotag` понимал сырой HTML без потери защиты от XSS.

## 2. CLI-миграции (`db:migrate`)
**Проблема:** Обновление структуры БД на сервере требует захода в админку.
**Решение:** Написать CLI-команду, которая читает `*.resource.php` и синхронизирует таблицы БД без браузера (для CI/CD).

## 3. Инструменты ИИ-агента (MCP / CLI)
**Проблема:** ИИ-агенты пока не могут напрямую управлять структурой.
**Решение:** Написать скрипты для ИИ: `make:resource`, `make:page`, `make:migration`, чтобы агент мог генерировать код одной командой.
