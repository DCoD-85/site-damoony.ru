# Задачи: Безопасность и Данные

## 1. Защита от RCE через файлы ресурсов
**Проблема:** `*.resource.php` — это исполняемый PHP-код. При взломе админки злоумышленник может внедрить вредоносный код.
**Решение:** Перевести формат `*.resource.php` в строгий JSON/YAML или валидировать файлы перед записью. Запретить редактирование PHP-кода через веб-интерфейс (только через Git).

## 2. Мультиязычность (i18n) в CRUD
**Проблема:** В новой Resource-Driven архитектуре нет механизма переводов для БД.
**Решение:** Добавить в `*.resource.php` флаг `'translatable' => true`. Создать таблицу `*_translations`. В админке автоматически генерировать табы для языков (ru, en).

## 3. Query Builder для сложных запросов
**Проблема:** `DataGateway` умеет только простые SELECT/INSERT/UPDATE. Для маркетплейса нужны JOIN, GROUP BY, агрегации.
**Решение:** Дописать легкий Query Builder (методы `join()`, `where()`, `groupBy()`), не изобретая тяжелый ORM.
