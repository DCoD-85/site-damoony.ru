## Разбор проекта `damoony2.ru`

### Запись 1: `www/.htaccess`
- Настройки PHP: `max_execution_time 5000`, `upload_max_filesize 2000M`, `post_max_size 2000M`, `max_input_vars 100001`, `memory_limit 512M`.
- Отключены: `magic_quotes_gpc`, `magic_quotes_runtime`, `register_globals`.
- `RewriteEngine On`, `RewriteBase /`.
- Кодировка: `AddDefaultCharset UTF-8`, `AddCharset UTF-8 .php .html`.
- `Options +FollowSymlinks`, `DirectoryIndex index.php index.htm index.html`, `Options -Indexes`.
- Правило для `tests`: если в пути есть `tests`, переписывает на `tests?%{QUERY_STRING}`.
- Далее — набор `RewriteCond` с `[OR]` и правилами:
  - статика (`css|js|png|jpg|jpeg|gif|svg|ico|woff|woff2|ttf|eot|map`) отдаётся напрямую `[L]`;
  - всё остальное уходит на `index.php?%{QUERY_STRING}`.
- Условия `RewriteCond` выглядят избыточными/противоречивыми, но фактически работают как «всё в index.php, кроме статики».

### Запись 2: `www/index.php` (файл `PHP.txt`)
- Точка входа.
- **Роутинг `/admin/`** до `session_start()` и до заголовков:
  - разрешены `127.0.0.1`, `::1`;
  - дополнительно IP берутся из `../config/site.config` → `admin.ips`;
  - если IP разрешён → `admin/bootstrap.php` и `exit`;
  - иначе — падение дальше в основной движок.
- **Определение `$host`**: отрезает поддомены, оставляет последние 2 сегмента (`www.damoony2.ru` → `damoony2.ru`).
- **Сессия**:
  - cookie: `path=/`, `domain=.$host`, `secure=true`, `httponly=true`, `samesite=Lax`;
  - если `PHPSESSID` уже есть — сначала `setcookie()`, потом `session_start()`;
  - `secure=true` означает, что сессия будет работать только по HTTPS. В OSPanel по HTTP может не работать.
- `Error_Reporting(E_ALL & ~E_NOTICE & ~E_DEPRECATED)`.
- Константы: `SCRIPTSTART_MT`, `SCRIPTSTART_HR`, `DS`, `DSA`, `BR`, `SIMPLECMS`.
- Странность: `if (!defined(TRUE)) define('GDEF_SECURE_CONSTANT','TRUE');` — скорее всего баг, проверяется не то.
- Функции: `error()`, `error_file()`, `warning_file()`, `error_class()`. `error()` пустая.
- Подключения:
  - `constants.php`
  - `included.php`
  - `main.php`
- Запуск:
  - `$main_settings = new main_settings();`
  - `$main = new main($main_settings);`
  - `$main->main();`

### Риски / заметки
- `secure=true` для cookie — сессия только по HTTPS.
- Дублирование `setcookie('PHPSESSID')` + `session_start()`.
- `defined(TRUE)` — почти наверняка ошибка.
- `.htaccess`: условия `RewriteCond` выглядят запутанно, но не ломают основную логику.
- `error()` пустая — реального вывода ошибок нет.


## Дополнения к карте проекта

### Запись 3: `www/constants.php`
- `DS` = `DIRECTORY_SEPARATOR`, `DSA` = `/`.
- Debug-флаги: `GL_LOG`, `GL_DEBUG`, `GL_DEBUGHARD` — по умолчанию `false`.
- Лимиты БД: `DB_LIMIT_ONE=1`, `DB_LIMIT_PAGE=10`, `DB_LIMIT_MAX=1000`.
- `VISUOLINK_RAND_DEFAULT=true`.
- Всё через `if(!defined(...))` — можно переопределить раньше.

### Запись 4: `www/included.php`
- Хелперы для include:
  - `fo([file,line,method])` → строка формата `method [ file:line ]`.
  - `bad($fo, $title, $message)` — рисует HTML-ошибку и `die()`. Закомментирован вариант через `visuotag`.
  - `include_bad($fo, $file)` — обёртка `bad()` для include-ошибок.
  - `include_my($fo, $file)` — `include_once` с вызовом `include_bad` при провале.
  - `include_array($fo, $files, $classes, $release_path)` — пачкой подключает файлы, проверяет наличие классов.
- CSS для ошибок: `/bad/main.css`.

### Запись 5: `www/main.php`
- **Класс `main`** — центральный диспетчер.
  - Публичные свойства: `main_path`, `main_settings`, `render`, `user`, `blacklist`, `vardump`, `log`, `core`, `db`, `library`, `language`, `messages`, `mod`, `visuopage`, `domain`, `allias`, `alliasglobal`, `alliasscheme`, `dataprovider`, `algoritm_`, `algoritm`, `visuorelease`, `visuostruct`, `visuolog`, `algoritm_class[]`, `release_min`.
  - `__construct(main_settings)` — если передан `main_settings`, зовёт `->main($this)`, иначе создаёт новый.
  - `path($url)` — устанавливает `main_path`.
  - `init()`:
    - подключает `../sources/include.php`;
    - создаёт `visuorelease`, `visuopage`, `visuostruct`, `render`, `core`;
    - создаёт `user`, `blacklist`, `log`, `vardump`, `db`, `library`, `language`, `messages`, `mod`;
    - `main_settings->init()`, `set('connect_type','http://')`;
    - `language->load()->init()`;
    - подключает `logic/<logic_ver>/include.php`;
    - `blacklist->init()`;
    - открывает БД `login_damoony`, `user->authorized()`.
  - `logic()`:
    - берёт `url` из `library`;
    - `domain_accepted(false)` → namespace домена;
    - `allias_accepted()` → имя аллиаса;
    - если пусто → 404 + `die('Not Found')`;
    - создаёт `domain`, `dataprovider`, `allias`, `alliasglobal`, `alliasscheme` — все динамически из namespace домена;
    - создаёт `algoritm` из namespace `domain\allias\algoritm`, вызывает `clear()`, `start()`, `debug()`.
  - `savedata()` — `language->savedefaults()`.
  - `release($log,$debug)` — прогоняет `alliasglobal->scripts`, затем `render->release()`.
  - `main($address)` — `path → init → logic → savedata → release(GL_LOG, GL_DEBUG)`.
  - `redirect($address)` — печатает REDIRECT, `path → main_settings->init → logic`.
  - `main_error()` — приватный, `die()` с HTML.
  - `is_guest()`, `is_auth()` — guard-хелперы.
- **Класс `main_path`** — парсит URL регуляркой:
  - `set($path)` — если пусто, собирает из `REQUEST_SCHEME://SERVER_NAME/REQUEST_URI`;
  - хранит `domain` и `url`;
  - `get_domain()`, `get_url()`.
- **Класс `main_settings`** — конфиг + домен/аллиас-логика:
  - поля: `domain_real_name`, `allias_real_name`, `language`, `render`, `logic='alpha.0.0'`, `skin`, `skin_allias='www'`, `connect_type`, `title`, `domains_real[]`, `domains_available[]`, `alliases_real[]`, `alliases_available[]`, `domains_namespace[]`, `domains_titles[]`, `domains_skins[]`, `fillers[]`, `render_engine=['default'=>'algoritm']`.
  - `__construct` — берёт `render/language/skin` из cookie или дефолтов.
  - `init()`:
    - грузит 4 конфига: `site.config`, `render.config`, `lang.config`, `secure/db.secure`;
    - язык: URL-сегмент приоритетнее cookie; разрешены `ru-ru`, `en-en`, `ch-ch`;
    - `domain_real_name = domains_real[url_allias[0]]`;
    - `allias_real_name = alliases_real[domain_real_name][url_allias[1] ?? '']`;
    - `skin_allias = allias_real_name`.
  - `loadExternalConfig($path)` — читает JSON, обновляет существующие свойства.
  - `main($main)` — сеттер.
  - `domains($name)`, `alliases($name)` — геттеры (второй пустой).
  - `domain_accepted($full=true)`:
    - если домен не в `domains_available` → `null`;
    - если `$full=false` → `domains_namespace[domain]` (или `domain` без `.ru`).
  - `allias_accepted()` — проверяет `alliases_available`.
  - `engine()` — выбирает движок из `render_engine` по аллиасу, fallback `algoritm`.
  - `default($language,$render,$skin)` — устанавливает дефолты + `connect_type='https://'`.
  - `set($var,$val,$convert)`, `get($var)`.
  - `skin($option)` — `'skin'` → `domains_skins[domain]` или `$this->skin`; `'allias'` → `skin_allias`.
  - `title()` — `domains_titles[domain]` или общий `title`.

### Запись 6: `www/admin/bootstrap.php`
- Изолированная точка входа админки (не использует `main.php`/`visuo`).
- Сессия: имя `admin_sid`, cookie `path=/`, `domain=''`, `secure` только при HTTPS, `httponly`, `samesite=Lax`.
- Константы: `ADMIN_ROOT`, `PROJECT_ROOT`, `CS_ROOT`, `CS_LIB`, `CS_CMD`, `CS_TPL`.
- Подключает `corescripts/_lib`: `Fs`, `Config`, `Template`, `Validate`, `Result`, `Context`.
- Подключает `admin/_lib`: `Auth`, `View`, `WebRenderer`, `Csrf`.
- `$auth = new Auth()`.
- `$p = $_GET['p'] ?? 'dashboard'`.
- Роуты:
  - `login` — POST проверяет `$auth->login()`, `View::render('login')`.
  - `logout` — `$auth->logout()`.
  - защита: `!$auth->check()` → редирект на login.
  - CSRF-guard для всех POST кроме login.
  - `dashboard` — читает `site.config`, строит список доменов (ns, avail, fs, alliases).
  - `domain:new`, `allias:new` — команды `DomainNew`, `AlliasNew`.
  - `domain:edit` — валидация title/skin, `Scan::skinsFor()`, сохранение `domains_titles/domains_skins`.
  - `domain:toggle`, `allias:toggle` — переключение `domains_available`/`alliases_available` (POST).
  - `domain:remove`, `allias:remove` — подтверждение + команды `DomainRemove`/`AlliasRemove`.
  - `pages:tree` — `Scan::pageTree()` по `www/logic/<logic>/domain/<domain>/allias/<allias>/algoritm`.
  - `page:edit` — валидация пути, чтение/запись `.data.json` (`default.available/auth/search/default`).
  - `page:new` — команда `PageNew`.
  - `allias:list` — список аллиасов домена + fillers.
  - `page:toggle` — переключение флагов в `.data.json`.
  - `filler:new` — команда `FillerNew` + включение в `fillers`.
  - `settings` — `SettingsSet` (только `logic`, `connect_type`).
  - `default` — 404.

### Замеченные моменты
- `main::logic()` использует `new ($static_domain.'\\dataprovider')` — динамические классы из namespace домена (`damoony_ru\...`).
- `main_settings::loadExternalConfig()` обновляет только уже существующие свойства — новые ключи из JSON игнорируются.
- `main_settings::alliases()` — пустой метод-заглушка.
- `site.config.admin.ips=[]` — админка доступна только с localhost (`127.0.0.1`, `::1`).
- `bootstrap.php` не проверяет `admin.login` из конфига — это внутри `Auth`.
- `page:edit` / `page:toggle` перезаписывают `.data.json` с конвертацией 4 пробелов в табы.
