# Alogic — Явный роутер

## 🛡 Безопасность и валидация
- **Белый список:** Создаются только классы из `routes.php`.
- **Якоря:** Регулярные выражения строго якорятся (`^...$`).

## 🔐 Поведение `auth: true`
Если маршрут защищен, а пользователь — гость:
- **При SSR (обычный запрос):** Вызывается `algoritm_auth` (обычно редирект на `/login`).
- **При AJAX (SPA-режим):** `visuostruct->min()` возвращает JSON с ошибкой `401 Unauthorized`, JS показывает уведомление или делает редирект.

## Пример маршрутов (`routes.php`)
```php
$router->add('/{lang:[a-z]{2}-[a-z]{2}}/docs', 'algoritm_lang_docs');
$router->add('/{lang:[a-z]{2}-[a-z]{2}}/profile/{login:[A-Za-z0-9_-]+}', 'algoritm_lang_profile');
```
