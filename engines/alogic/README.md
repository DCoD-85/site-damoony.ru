# Alogic — Явный роутер

Движок маршрутизации, заменяющий магию имен файлов на явную карту (`routes.php`).

## 🛡 Безопасность и валидация
- **Белый список:** Роутер создает только те классы, которые прописаны в `routes.php`. Прямой подстановки имени класса из URL нет (защита от LFI).
- **Валидация параметров:** Регулярные выражения в маршрутах строго якорятся (`^...$`). Обязательно используйте регулярки для `{lang}`, чтобы избежать Path Traversal.
- **Проверка `auth`:** Если в `.data.json` указано `auth: true`, а пользователь — гость, движок автоматически вызывает `algoritm_auth` (редирект или 403).

## Пример маршрутов (`routes.php`)
```php
use alogic\Router;
$router = new Router();

// Статика (выше динамики)
$router->add('/{lang:[a-z]{2}-[a-z]{2}}/docs', 'algoritm_lang_docs');

// Динамика (строгая регулярка)
$router->add('/{lang:[a-z]{2}-[a-z]{2}}/profile/{login:[A-Za-z0-9_-]+}', 'algoritm_lang_profile');
```

**Приоритет:** Маршруты проверяются в порядке добавления (сверху вниз).
