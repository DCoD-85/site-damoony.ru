# 🚀 SimplCMS (Damoony)

**SimplCMS** — высокопроизводительная гибридная CMS для управления мультидоменной сетью сайтов. 
Архитектура построена на принципах **File-Based Routing**: структура сайта хранится в файлах (JSON), а база данных используется только для динамического контента.

## 📌 Ключевые особенности
*   **Единый движок маршрутизации (`tree`)** — предсказуемый file-based роутер, заменивший устаревшие `chain` и `router`. URL физически соответствует вложенности папок.
*   **Мультидоменность «из коробки»** — управление десятками доменов и аллиасов через единый `site.config`.
*   **UI-движок Visuo** — генерация HTML через ООП-билдер (`visuotag`, `visuoel`), исключающая XSS и позволяющая переиспользовать компоненты.
*   **Высокая скорость** — отсутствие тяжелых SQL-запросов для рендера страниц (структура читается из JSON).
*   **Надежность** — 435+ зеленых тестов (включая кастомный визуальный раннер и PHPUnit).

## 🏗 Архитектура (Кратко)
`Data (JSON) -> Tree Router (Файловый роутер) -> Logic (PHP) -> Render (Visuo)`
1.  `engine/tree.php` — читает URL и находит соответствующий PHP-класс страницы, опираясь на `.rules.json`.
2.  `app/` — содержит бизнес-логику конкретных доменов и аллиасов.
3.  `visuo/` — собирает финальное HTML-дерево.

## ⚙️ Требования
*   **PHP 8.2+** (строгая типизация, неймспейсы).
*   **MariaDB** (только для контента, например статей или пользователей).
*   **Composer** (для dev-зависимостей и автозагрузки).

## 🚦 Быстрый старт
1.  Клонируйте репозиторий.
2.  Настройте веб-сервер (Nginx/Apache) на папку `/www`.
3.  Проверьте конфигурацию в `/config/` (файлы `engine.config`, `site.config`, `admin.config`).
4.  Админка доступна по адресу `/admin/` (по умолчанию логин `admin`).
5.  Запустите тесты для проверки целостности: 
    *   Визуально: `https://<ваш_домен>/tests/`
    *   CLI: `vendor/bin/phpunit`
