# Damoony2 — Lightweight Multi-Domain PHP Framework

**Damoony2** — легковесный мультидоменный микро-фреймворк с собственной маршрутизацией и независимым HTML-билдером. Работает на **PHP >= 8.4** (используются `typed properties`, `mixed`, `match`).

## 🏗 Архитектура (4 слоя)
1. **`engine/`** — Ядро (`main`, `db`, `user`, `middleware`, автозагрузчик).
2. **`engines/`** — Сменные движки маршрутизации (Strategy):
   - `legacy/` — старый движок (файловая магия).
   - `alogic/` — новый движок (явные маршруты).
3. **`app/`** — Бизнес-логика (домены, аллиасы, страницы). Не знает о роутере.
4. **`visuo/`** — Независимый HTML-билдер. Общается с ядром через `VisuoHost`.

## 🌐 3 состояния (режима) работы
1. **SSR (No JS)** — Полная перезагрузка. Всегда работает (SEO-friendly).
2. **With JS** — JS перехватывает формы/ссылки, но страница рендерится целиком.
3. **SPA (AJAX)** — Подгрузка блоков (`dt_center`) без перезагрузки. JS обновляет `<title>`, `<meta>` и `history.pushState`. Прямой заход на URL всегда отдаёт полноценный SSR-ответ.

## 🧪 Тесты и Инструменты
- **435 тестов** (PHPUnit + браузерный раннер): Unit для `visuo` (430) + Integration для `alogic`/`legacy` (5).
- **PHPStan Level 5** — `[OK] No errors` (baseline 439).
- Роутер тестируется в обоих режимах (`legacy` / `alogic`).

## 🚀 Запуск
1. Точка входа: `www/index.php`.
2. Переключение движка: `config/site.config` -> `"logic_type": "alogic"` (per-request, на уровне сайта).
3. Тесты: `http://ваш_домен/tests/index.php`.
