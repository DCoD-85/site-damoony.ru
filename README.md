# 🚀 SimplCMS (Damoony)

**SimplCMS** — высокопроизводительная гибридная CMS для управления мультидоменной сетью сайтов. 
Архитектура построена на принципах **File-Based Routing**: структура сайта хранится в файлах (JSON), а база данных используется только для динамического контента.

## 📌 Ключевые особенности
*   **Единый движок маршрутизации (`tree`)** — предсказуемый file-based роутер. URL физически соответствует вложенности папок.
*   **Resource-Driven CRUD** — чтобы создать новую сущность (статьи, товары), достаточно описать её в одном файле `*.resource.php`. Админка сама сгенерирует интерфейс и обновит структуру БД.
*   **MVC-архитектура админки** — легкий собственный роутер (`AdminRouter`) и изолированные контроллеры вместо гигантских `switch`.
*   **Мультидоменность «из коробки»** — управление десятками доменов и аллиасов через единый `site.config`.
*   **UI-движок Visuo** — генерация HTML через ООП-билдер (`visuotag`, `visuoel`), исключающая XSS.
*   **Безопасность** — система инвайтов, fingerprint-авторизация, белые/черные списки IP.
*   **Надежность** — 469+ зеленых тестов (PHPUnit) и строгий статический анализ (PHPStan).

## 🏗 Архитектура (Кратко)
`Data (JSON) -> Tree Router (Файловый роутер) -> Logic (PHP) -> Render (Visuo)`
1.  `engine/tree.php` — читает URL и находит PHP-класс страницы, опираясь на `.rules.json`.
2.  `app/` — бизнес-логика доменов, аллиасов и ресурсы БД (`*.resource.php`).
3.  `www/admin/` — изолированная MVC-админка.
4.  `visuo/` — собирает финальное HTML-дерево.

## ⚙️ Требования
*   **PHP 8.4+** (строгая типизация, неймспейсы).
*   **MariaDB** (для динамического контента).
*   **Composer** (для dev-зависимостей).

## 🚦 Быстрый старт
1.  Клонируйте репозиторий.
2.  Настройте веб-сервер (Nginx/Apache) на папку `/www`.
3.  Проверьте конфигурацию в `/config/` (файлы `engine.config`, `site.config`, `admin.config`).
4.  Настройте подключение к БД в `secure/db.config`.
5.  Админка доступна по адресу `/admin/` (по умолчанию логин `admin`). 
6.  Для создания таблиц БД из файлов `*.resource.php` используйте кнопку «⚡ Синхронизировать БД» во вкладке «Данные».

## 🧪 Тестирование

*(Визуальный раннер тестов доступен в браузере по адресу `/tests/`)*
