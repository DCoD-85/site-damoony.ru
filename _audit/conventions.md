# Соглашения по именованию и структуре

Обновлено: 2026-09-17.

## Имена файлов и папок

РАЗРЕШЕНО:
  - латиница a-z A-Z
  - цифры 0-9
  - подчёркивание _
  - дефис -
  - точка .

ЗАПРЕЩЕНО:
  - пробелы в имени файла
  - em-dash (—) и en-dash (–)
  - кириллица в имени файла
  - слова "копия", "copy", "old", "bak", "backup" в рабочем имени

ПРИЧИНА: em-dash и пробелы ломают URL, шелл-команды и git.
Если файл — версия, он уезжает в _archive\ с датой в имени.

## Расширения

  .php        — исполняемый PHP-код
  .inc        — данные, подключаемые через include (PHP-массив, языковой пакет)
  .txt.inc    — текстовые конфиги, читаемые через file_get_contents
  .xml.inc    — XML-конфиги
  .config     — главный конфиг (secure/main_settings.config)
  .css, .js   — статика
  .md         — документация

## Индексы-заглушки

index.php в каждой папке (0 байт) — защита от листинга директорий.
Не удалять. Создавать в новых папках.

## Версионирование

Если файл — версия, он НЕ остаётся рядом с живым.
Порядок:
  1. Живой:    sources\db\db_mysqli.php
  2. Старый:   _archive\db_mysqli-class1.php
  3. Не "db_mysqli copy.php" и не "db_mysqli_old.php"

## Закомментированный код

Долго живущий закомментированный include — плохо.
Либо удалить, либо перенести в _archive\ и там оставить.
Пример: sources\include.php:7-10 (other/*) — теперь в _archive\sources-other\.

## Файлы для пометки времени

Все крупные изменения проекта фиксируются в _audit\cleanup-log.txt.
Формат: одна строка на действие, с датой YYYY-MM-DD.

## AJAX — обязательная фича

Добавлено: 2026-09-18.

### Что это даёт

Сайт работает **без физической перезагрузки страницы**.
Блоки (top, center, bottom, layers) обновляются через AJAX.
Фоновая музыка, плеер и другие долгоживущие элементы НЕ прерываются.

### Что НЕ отключать

- `form_jquery : true` в формах — включает AJAX-отправку.
- `ajax_guest()`, `ajax_logged()` в алгоритмах — обработчики AJAX-запросов.
- `data-form-jquery`, `data-load`, `data-ajax` на тегах — управляют JS-движком.
- `visuostruct_ajax` — структура JSON-ответа для AJAX.
- `release_struct( )`, `release_min( )` в `visuorelease` — формируют JSON.

### Правило

**AJAX включён по умолчанию.** Отключать только для теста/отладки.
Продакшн всегда работает в AJAX-режиме.

### Что это значит при правках

- Новые страницы — с `form_jquery : true` (если есть форма).
- Новые ajax-методы — не «заглушки», а обязательные.
- JSON-ответы — через `visuostruct`, не через `echo json_encode`.
- Никаких echo/print до release() — сломает AJAX-парсинг.
