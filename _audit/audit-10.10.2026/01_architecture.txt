================================================================
01_ARCHITECTURE — слои, связи, поток
================================================================

СЛОИ (снизу вверх)
----------------------------------------------------------------
  1. main (www/main.php)
     main_settings  — config/*.config
     main_path      — URL
     library        — url/link/language/user
     visuorelease   — рендер
     db / user / language / messages / ...

  2. domain (domain.php)
     domaininfo — имя + история
     подключает <domain>/{allias,alliaslocal,alliasglobal,
                          alliasscheme,dataprovider}.php

  3. allias (allias.php)
     alliasinfo
     подключает <allias>/include.php

  4. alliasglobal (alliasglobal.php)
     блоки: top/left/center/right/bottom/policy/debug
     скрипты: headers/head
     меню: alliasglobal_menu (+ row)
     база: alliasblock + alliasglobalscript + filler_trait

  5. alliasscheme (alliasscheme.php)
     5 схем: login/error/min/www/visuo
     каждая — каркас body + meta + слоты dt_*

  6. dataprovider (dataprovider.php + <allias>/dataprovider/)
     фасад домена → фасады аллиасов → БД

  7. algoritm (allias/<a>/algoritm/*)
     фреймворк роутинга URL → классы страниц
     algoritm_ + algoritmdata_ (база)
     <allias>/algoritm/algoritm.php — корневой
     <allias>/algoritm/lang/* — страницы

  8. user (allias/<a>/user.php)
     замена базового \user на allias-специфичный

ПОТОК
----------------------------------------------------------------
  index.php
    → constants.php + included.php
    → main.php (main_settings + main)
    → main->main() = path → init → logic → savedata → release
      init    : sources/include.php → подсистемы
      logic   : domain → dataprovider → allias → alliaslocal →
                alliasglobal → alliasscheme → algoritm(start)
      release : scripts->run() → render->release()
                → visuorelease->final() → visuorender->html()

FILLERS (alliasglobal)
----------------------------------------------------------------
  main_settings->fillers[<domain>][<allias>][<block>] = true
  true  → <block>/<block>_<allias>.php + data
  false → <block>.data.php

  Реализованы: top/left/center/right/bottom/policy/debug
  для visuo, www.

ФОРМАТЫ ОТВЕТА (visuostruct)
----------------------------------------------------------------
  null              → HTML (по умолчанию)
  visuostruct_html  → HTML + override слотов
  visuostruct_ajax  → JSON {error, address, layers{}}
  visuostruct_min   → JSON {error, messages, release, form, referer}
