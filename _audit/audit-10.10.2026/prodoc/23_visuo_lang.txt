================================================================
A. algoritm_lang.php — точка входа
================================================================
$available = ['', 'index', 'docs', 'news', 'downloads', 'download',
              'login', 'logout', 'registration', 'profile']

release()
    default = (url_base[1] ?? '') === ''
    algoritmdata->set($available, $auth, $search, $default)
    release_($this)

default()
    307 редирект на /{lang}/index/

РОЛЬ:
  /{lang}/          → default() → /{lang}/index/
  /{lang}/{segment} → include_ext() найдёт алгоритм страницы

================================================================
B. Каждая страница — общие черты
================================================================
Все extends \algoritm_.

ОБЩИЙ КАРКАС
  $available — что обрабатывает
  $auth      — требовать авторизацию
  $search    — разбирать ли URL regex
  $default   — вызвать ли default() если URL пуст

  release()  → algoritmdata->set + release_($this)
  guest()    — что показать гостю
  logged()   — что показать авторизованному
  default()  — обычно редирект или role()

ПАТТЕРН РЕНДЕРА
  head->title(...)
  new \visuoel()
  ve->block()->html()->data()->set(html)
  ve->message()->{info|success|error|warning}()->data()->set(text)
  center->visuotag()->el($ve)

================================================================
C. Страницы — сводка
================================================================

INDEX
  default через is_default()
  title VISUO_TITLE + PAGE_HOME
  div.visuo.visuo-index

DOCS
  $available = ['', '([a-z0-9-]+)|page']
  render_list() — дерево разделов + статьи (через dp->doc)
  Пишет h() + h() — экранирование ок

DOCS_PAGE
  $available = ['']
  render_page() — article_by_slug(url_base[2])
  404 — если нет
  Хлебные крошки, content_html не экранируется (доверие к источнику)

DOWNLOAD (промежуточный уровень)
  $available = ['([a-z0-9-]+)|page']
  $default = false
  default() → false (не обрабатывает сам, отдаёт вложенному download_page)

DOWNLOAD_PAGE
  $available = ['']
  serve() — проверка status=active, basename, realpath+VISUO_MEDIA_DOWNLOADS,
            лог increment_downloads, отдача через readfile()
  Заголовки: Content-Type, Content-Disposition attachment,
             Content-Length, X-Content-Type-Options, Cache-Control: no-store
  not_found() — 404 с ссылкой back

DOWNLOADS
  $available = ['']
  $search = false
  default() — если url_base[2] !== '' → false (мусор → error_())
  render_list() — all_active(), human_size()

LOGIN
  $available = ['login']
  $search = false
  guest → render() с формой
  logged → redirect на profile
  CSRF, POST → user->authorize → redirect_profile

LOGOUT
  guest → redirect home
  logged → user->logout() → redirect home

NEWS
  $available = ['', '([a-z0-9-]+)|page']
  render_list() — recent(20, lang_code)
  time_local с tz пользователя

NEWS_PAGE
  $available = ['']
  by_slug(slug, lang_code)
  Если пусто и lang_code !== 'ru-ru' → fallback на ru-ru + warning
  404 при пустом

PROFILE
  $auth = true
  POST: update_timezone/update_lang
  info table + form (tz + lang)

REGISTRATION
  $available = ['registration']
  guest → render() с формой
  logged → redirect на profile
  POST → user->register() → success-сообщение + ссылка на login

================================================================
D. Поток /{lang}/{segment}/
================================================================
  algoritm (visuo) → release() → release_(this)
    algoritmdata->set(['lang-regex'], false, true, true)
    include_ext()
      url_base_pos = 3 (в get_class 3 подчёркивания?)
      URL /ru-ru/docs/ → base[3]?
      → algoritm_lang с $available
        → algoritm_lang_index/docs/news/...
        → algoritm_lang_docs_page и т.п.

ЗАМЕЧАНИЯ
- В INDEX-файле осталась отладка (wrapper_set div1/div2/div3,
  section_add test/test2/test3, content(time())) — надо убрать.
- DOWNLOAD/DOWNLOAD_PAGE — разделены специально: промежуточный
  уровень сохраняет slug в url_base[2], а конечный его читает.
- LOGIN/REGISTRATION/LOGOUT/PROFILE — CSRF-защита через csrf_check().
- Везде используется \visuoel (новый элементный API)
  вместо visuoelement.
- Ошибки/успехи — message()->{info|success|error|warning}().
