================================================================
26_ALLIASSCHEME — alliasscheme/*.php
Схемы аллиасов: каркас body + meta + слоты dt_*.
================================================================

КЛАССЫ (namespace damoony)
  alliasscheme             — контейнер + load/reload
  alliasscheme_login       — схема login
  alliasscheme_error       — схема error
  alliasscheme_min         — минимальная (только center)
  alliasscheme_www         — схема www
  alliasscheme_visuo       — схема visuo

РОЛЬ
  Каждая схема — отдельный «движок» body:
    meta()          — собирает CSS/JS в visuorelease->meta()
    body()          — строит HTML-каркас
    body_preload()  — div#tb_preload + div#tB_load и т.п.
    init()          — находит в дереве слоты dt_*
    refresh()       — заливает в слоты as_tag() соответствующих блоков
    load()          — meta → body → init → refresh
    reload()        — clear + load

  Схема не имеет своих классов данных — работает с already-created
  alliasglobal блоками (top/left/center/right/bottom/policy).

================================================================
A. alliasscheme.php — контейнер
================================================================
СВОЙСТВА
  main, schemename, autoload (bool)
  login, error, min, www, visuo — по одному объекту схемы

МЕТОДЫ
  __construct( main ) → autoload()
  autoload(bool $autoload = true, bool $init = true)
      Если $autoload — include 5 файлов схем.
      Если $init — init()
      БАГ: $this->autoload = $init — поле затирается.
  init( ) — new всех 5 схем
  load( string $schemename )
      $this->schemename = $schemename
      $this->{schemename}->load()
  reload( )
      $this->{schemename}->reload()

================================================================
B. Общий каркас схемы (на примере visuo)
================================================================
СВОЙСТВА
  main, alliasscheme, visuorelease
  dt_root, dt_top, dt_middle, dt_left, dt_center,
  dt_right, dt_bottom, dt_policy

meta()
    $skin   = main_settings->skin('skin')
    $allias = main_settings->skin('allias')
    $meta = visuorelease->meta(); $meta->clear()
    favicon + CSS скина + CSS движка visuoel + JS + CDN (plyr)

body_preload()
    div#tb_preload
    div.popupload (bg-nav + result)      ← в visuo/www/login
    div#tB_load > .preresult > table    (td.left | td.result | td.right)
    div#tB_messages, div.tB_tmp, div.tB_modules

body()
    visuorelease->visuotag_clear()
    строит:
      !doctype
      html.cl_html.scheme_<name> [guest|logged]
        head.cl_head
        body.cl_body
          append(body_preload())
          div#popup_result
          div.dt
            div.dt_top
            div.dt_middle
              div.dt_left
              div.dt_center
              div.dt_right
            div.dt_bottom
          div.dt_policy
          div.dt_debug
    visuorelease->visuotag_set($vt)

init()
    $vt = visuorelease->visuotag()
    dt_root   = $vt->root()
    dt_top    = dt_root->find(class:'dt_top')
    dt_left   = dt_root->find(class:'dt_left')
    dt_center = dt_root->find(class:'dt_center')
    dt_right  = dt_root->find(class:'dt_right')
    dt_bottom = dt_root->find(class:'dt_bottom')
    dt_policy = dt_root->find(class:'dt_policy')

refresh(bool $reload = false)
    $top    = alliasglobal->top->as_tag()
    $left   = alliasglobal->left->as_tag()
    $center = alliasglobal->center->as_tag()
    $right  = alliasglobal->right->as_tag()
    $bottom = alliasglobal->bottom->as_tag()
    $policy = alliasglobal->policy->as_tag()
    Каждый в свой слот через ->clear()->append($x)

load() / reload()
    load:  meta → body → init → refresh
    reload: clear meta → clear → meta → body → init → refresh(true)

================================================================
C. Различия между схемами
================================================================
login           — CSS/JS под login (plyr, visuoel), слот dt_policy есть
error           — CSS error.css + те же скины; слотов меньше
min             — meta() пустой; body() = только div.dt_center
www             — CSS под www.damoony.ru + shared; JS + engine; слот policy
visuo           — CSS под damoony.ru; JS + plyr; слоты left/center/right +
                  policy + debug

ВСЕ ПЯТЬ создаются всегда при alliasscheme::init(),
даже если аллиас использует только одну.

================================================================
D. Поток вызова (visuo)
================================================================
main::logic()
  new \damoony\visuo\algoritm($main)
    boot_user()
  algoritm->start()
    alliasscheme->load('visuo')       ← meta + body + init + refresh
    algoritm->logic()                 ← CORS
    algoritm->release()               ← роутинг по URL
    alliasscheme->reload()            ← повтор после algoritm (уже с контентом)

================================================================
ЗАМЕЧАНИЯ
================================================================
1. alliasscheme::autoload() — баг: поле $autoload затирается $init.
2. body() каждой схемы почти идентичен — сильное дублирование.
   Общий шаблон можно вынести в базовый класс.
3. load()/reload() вызываются из алгоритма дважды (загрузка «до»,
   reload «после») — каркас пересобирается.
4. dt_middle есть в свойствах, но в body() вложен как контейнер
   без find() — намеренно.
5. Порядок CSS/JS для схем захардкожен — если добавят новый
   CSS, надо править все схемы.
