СЕКЦИИ (в порядке исполнения)

[0] ТАЙМИНГ
    $start    = microtime(true)
    $start_hr = hrtime(true)
    → позже сохраняются в константы SCRIPTSTART_MT / SCRIPTSTART_HR
    → используются для замеров времени рендера.

[1] ОПРЕДЕЛЕНИЕ HOST
    $host = HTTP_HOST без поддомена.
    Трюк: strrev → explode('.', ..., 3) → берём первые 2 части
          → strrev обратно.
    Пример: login.damoony2.ru → damoony2.ru
    $host нужен для session_set_cookie_params (cookie на .damoony2.ru).

[2] ЗАГОЛОВКИ
    Content-Type: text/html; charset=UTF-8
    (вариант application/json — закомментирован).

[3] СЕССИЯ
    Есть два варианта (version 1 — закомментирован, version 2 — рабочий).

    version 2 (активный):
      session_set_cookie_params([
        lifetime=0, path='/', domain='.' . $host,
        secure=true, httponly=true, samesite='Lax'
      ])
      Если пришёл PHPSESSID — переустанавливаем cookie с новым domain
      (миграция сессии на .$host), затем session_start().
      Иначе — просто session_start().

[4] ОШИБКИ
    Error_Reporting( E_ALL & ~E_NOTICE & ~E_DEPRECATED )
    display_errors НЕ включается (закомментировано).
    → notice'ы и deprecation молчат, warning'и и выше — показываются.

[5] КОНСТАНТЫ ВРЕМЕНИ
    SCRIPTSTART_MT = $start
    SCRIPTSTART_HR = $start_hr

[6] ГЛОБАЛЬНЫЕ КОНСТАНТЫ
    GDEF_SECURE_CONSTANT = 'TRUE'   (защита от прямого include)
    DS  = DIRECTORY_SEPARATOR       (разделитель ФС)
    DSA = '/'                       (разделитель адресной строки)
    BR  = PHP_EOL
    SIMPLECMS = true                (флаг самописной CMS)

    ВНИМАНИЕ (баг):
      `if ( ! defined( TRUE ) )` — defined() ожидает строку,
      а получает bool (приводится к "1"). Условие всегда true →
      константа GDEF_SECURE_CONSTANT переопределяется всегда.
      Формально — не ломает, но лучше: `! defined('GDEF_SECURE_CONSTANT')`.

[7] ФУНКЦИИ ОШИБОК (глобальные, определены в этом файле)
    error()         — die() с HTML-страницей ошибки. Параметры:
                       title, message, file, line.
                       Скрывает DOCUMENT_ROOT → '..' в пути.
                       Опционально показывает phpinfo() при ?phpinfo=phpinfo.
    error_file()    — обёртка error() для неудачного include.
    warning_file()  — заглушка (пустое тело, чтобы не сыпать warning'и).
    error_class()   — обёртка error() для отсутствующего класса.

[8] ПОДКЛЮЧЕНИЕ ЯДРА
    ( include_once __DIR__ . DS . 'constants.php' ) or error_file(...)
    ( include_once __DIR__ . DS . 'included.php'  ) or error_file(...)
    ( include_once __DIR__ . DS . 'main.php'      ) or error_file(...)

    Порядок:
      1. constants.php — константы (пути, режимы).
      2. included.php  — базовые include'ы (автолоадер, утилиты).
      3. main.php      — классы main_settings и main.

[9] СТАРТ СИСТЕМЫ
    $main_settings = new main_settings()
    $main = new main( $main_settings )
    $main->main()      ← вся дальнейшая логика отсюда.

    Переменная $url — закомментированный тестовый хвост, не используется.

БАГИ / ЗАМЕЧАНИЯ
----------------------------------------------------------------
1. defined( TRUE ) — см. [6]. Работает случайно.
2. $_GET['phpinfo'] без isset() → notice при отсутствии.

   подделан, домен для cookie будет установлен по нему.
   Для CLI/не-HTTP запуска — fatal (нет HTTP_HOST).
4. $url = null; // ... — мёртвый код.
5. Ветка "version 1" session — закомментирована, но висит в файле.
