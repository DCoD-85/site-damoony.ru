A. visuolink.php — фабрика <link>/<script>
================================================================
РОЛЬ
  visuometa::link() возвращает visuolink. Через него добавляют
  favicon / css / js. Каждый вызов создаёт новый подкласс и
  запоминает тип — release/as_tag идёт по этому типу.

ФАЙЛ СОДЕРЖИТ 4 КЛАССА
  visuolink           — фасад + 3 подкласса
  visuolink_favicon   — <link rel="icon" ...>
  visuolink_css       — <link rel="stylesheet" ...>
  visuolink_js        — <script src="..." type="text/javascript">

class visuolink
  visuometa : visuometa
  type      : 'favicon' | 'css' | 'js' | ''
  favicon / css / js : ?visuolink_<type>  — последний созданный

  ФАБРИКИ
    favicon($href, ?bool $rand = null) : visuolink_favicon
    css($href, ?bool $rand = null)     : visuolink_css
    js($href, ?bool $rand = null)      : visuolink_js
    Каждая: this->type = '<name>'; this-><name> = new ...

  as_tag() : visuotag
    Guard: если type не в whitelist [favicon,css,js] → пустой visuotag.
    Если соответствующий подкласс === null → пустой visuotag.
    Иначе → delegat подклассу.

  STATIC
    resolve_rand(?bool $rand) : bool
      Приоритет: $rand !== null → $rand
                 иначе VISUOLINK_RAND_DEFAULT (если определено)
                 иначе false
    apply_rand(string $href, bool $rand) : string
      Если $rand=false или href='' → href как есть.
      Иначе — добавляет cache-buster: случайное число 10000–99999.
      Корректно работает с '?' в URL и с '#'-якорем.

class visuolink_favicon
  d_rel='icon', d_href (переданный, с rand), d_type='image/x-icon'
  as_tag() → <link rel="icon" href="..." type="image/x-icon" />

class visuolink_css
  href (с rand)
  as_tag() → <link href="..." type="text/css" rel="stylesheet" />

class visuolink_js
  href (с rand)
  as_tag() → <script src="..." type="text/javascript"></script>

ЗАМЕЧАНИЯ
- favicon/css — самозакрывающиеся <link> (visuotag с tag_closed=false).
- script — с закрывающим тегом (tag('script'), по умолчанию true).
- apply_rand — cache-buster. random_int — безопасный.
- visuometa не хранит список ссылок; каждая css()/js() сразу
  создаёт новый visuolink и кладёт в elements[].

ПРИМЕР
  $meta->link()->css('/media/main.css');
  $meta->link()->js('/media/engine.js', rand: true);
  $meta->link()->favicon('/favicon.ico');

B. visuolog.php — лог для debug-панели
================================================================
РОЛЬ
  Двухуровневый лог: visuolog (контейнер) + visuolog_row (запись).
  Заполняется автоматически из visuotag::tag()/find()/release() и
  из visuometa/title/link. Показывается в debug-панели.

class visuolog
  settings_online : bool = false   — печатать строку сразу (debug)
  rows            : array of visuolog_row
  rows_count      : int            — нумератор
  time            : float          — (не используется в этом файле)
  html            : string         — (не используется)

  __construct(bool $online = false)

  add($message, $method, $file, $line) : void
    Подрезает DOCUMENT_ROOT → '...' в $file.
    new visuolog_row($this) + row->add(...)
    rows[] = row
    Если settings_online=true — сразу print row->release()

  as_tag() : visuotag
    div.log
      если rows пусто → div.log_row_empty «Лог пустой...»
      иначе → append(row->as_tag($num)) для каждого

  release() : string
    Если rows пусто → '<div>Лог пустой...</div>'.
    Иначе — конкатенация row->release() (HTML-строки).

  final() : void
    Если settings_online=false → print release() (выводит лог).
    Если true → die('<div>Log is end</div>').

class visuolog_row
  visuolog : visuolog
  hrtime   : float (на момент add)
  row_num  : int
  message / method / file / line : string
  datetime : ?DateTime

  add($message, $row_num, $method, $file, $line) : void
    hrtime = hrtime(true)
    datetime = new DateTime()
    сохраняет поля

  as_tag(int $number) : visuotag
    Считает Δ микросекунд от предыдущей записи:
      microtime_prev = rows[number-1]->hrtime
      или $GLOBALS['start_hr'] для первой
      Δ в миллисекундах: number_format(delta / 1000000, 3)
    Строит:
      div.log_row
        div.log_row_num       (row_num)
        div.log_row_message   (message)
        div.log_row_method    (method file:line)
        div.log_row_microtime (+Δ)
        div.log_row_datetime  (d-m-Y [ H:i:u ])

  release() : string
    HTML-строка с inline-стилями (grid-layout).
    Формат времени 'H:i:u d-m-Y'.

ЗАМЕЧАНИЯ
1. Логирование на каждый tag()/find()/release() — при построении
   сложной страницы rows может стать большим. Ограничений нет.
2. as_tag и release дают разные форматы — as_tag использует CSS-классы,
   release — inline-стили. Оба существуют.
3. settings_online=false (default) → строки НЕ печатаются сразу,
   только накапливаются. final() печатает всё разом.
4. В as_tag($number) первый row берёт опору из $GLOBALS['start_hr']
   — это константа SCRIPTSTART_HR из index.php? Надо проверить.
   Переменная $start_hr тоже есть в index.php, но не в $GLOBALS.
   Возможно, не подхватится — тогда Δ = 0.
5. datetime форматируется с 'u' — микросекунды.

C. visuorelease_settings.php — настройки рендера
================================================================
РОЛЬ
  Тонкий контейнер настроек для visuorelease. Пока одно поле — language.

class visuorelease_settings
  visuorelease : ?visuorelease
  language     : string = 'ru'   (private)

  __construct(?visuorelease)
    Если в cookie есть 'language' (непустая строка) — берёт оттуда.
    Иначе 'ru'.

  get($varname) : mixed
    property_exists($this, $varname) ? $this->{$varname} : null

  set($varname, $value) : $this
    property_exists → присвоить

ЗАМЕЧАНИЯ
1. language — private. Публичный доступ через get/set.
2. Значение 'ru' по умолчанию; сайт реально использует 'ru-ru', 'en-en',
   'ch-ch'. Здесь код без суффикса — вероятно, наследие.
3. Класс — расширяемая точка: если появятся другие настройки,
   просто добавить private-свойства и использовать get/set.
4. Параметр $visuorelease сохраняется, но нигде не используется
   в этом классе.
