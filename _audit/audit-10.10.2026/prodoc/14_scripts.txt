================================================================
A. alliasglobal_script_headers
================================================================
script_name = 'headers'
Создаётся ПЕРВЫМ в alliasglobal::init() — до блоков.

СВОЙСТВА
  langs_available : array = ['ru-ru','en-en','ch-ch']
  lang_default    : string = 'ru-ru'

init()
  handle_language()
  handle_skin()

handle_language()
  Правила:
    1. Язык — всегда первый сегмент URL.
    2. Приоритет: URL → cookie → default.
    3. Установка cookie 'language' и 'lang', если нужно.
    4. URL без языка → 307 редирект на URL с языком.

  Алгоритм:
    base0 = url_base[0]
    cookie_lang = $_COOKIE['lang']
    is_lang_url   = base0 in langs_available
    cookie_valid  = cookie_lang in langs_available
    lang = is_lang_url ? base0 : (cookie_valid ? cookie_lang : default)
    if !cookie_valid || cookie_lang !== lang:
      setcookie('language', …)
      setcookie('lang', …)
    if !is_lang_url:
      если base0 похож на код (^[a-z]{2}(-[a-z]{2})?$) → заменить base0
      иначе → вставить lang в начало
      link->href(url_domain, new_url_base, url_vars) → 307 exit

handle_skin()
  if $_GET['skin'] === '' → return
  setcookie('skin', $skin, 0, '/', $url_allias[0])
  href = link->href(url_domain, url_base, no_adress)
  header Location + exit

ЗАМЕЧАНИЯ
  1. Внутри handle_language() cookie ставится с 3 параметрами + $domain = url_allias[0],
     а не с .domain. Дублирование куки 'language' и 'lang' —
     возможный легаси.
  2. mb_ereg с '^[a-z]{2}…$' — если base0 = 'ru-RU' (регистр) — не сработает.
  3. Redirect всегда 307 (сохраняет метод). Для лендинга ок.

================================================================
B. alliasglobal_script_head
================================================================
script_name = 'head'
Создаётся вторым.

СВОЙСТВА
  title : string
  css   : array
  js    : array
  lang  : ?string

МЕТОДЫ
  title($t) / css($h) / js($s) / lang($l) — сеттеры
  run()
    if run_done → return
    meta = main->visuorelease->meta()
    if meta === null → return
    if title !== '' → meta->title()->data(title)
    foreach css → meta->link()->css(href)
    foreach js  → meta->link()->js(src)

ЗАМЕЧАНИЯ
  - $this->lang нигде не используется в run() — заглушка
    на будущее (html lang="…"?).
  - meta() может вернуть null — выход без ошибки, ок.
