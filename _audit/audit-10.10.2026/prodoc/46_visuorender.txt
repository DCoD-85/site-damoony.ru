================================================================
46_VISUORENDER — sources/visuo/sources/visuorender.php
Чистое преобразование visuotag + visuometa → HTML-строка.
================================================================

namespace: (глобальный)
ПОДКЛЮЧАЕТСЯ ИЗ: sources/visuo/visuo.php (шаг 17)
РОЛЬ:
  Финальный шаг рендера. Принимает готовое дерево + meta.
  Никакого состояния, никаких ссылок на main, никаких настроек.
  Только: meta → в <head>, потом prepare → release → final.

ВЫЗЫВАЕТСЯ ИЗ:
  visuorelease::final() → visuorender->html($vt, $meta)

================================================================
СВОЙСТВА
================================================================
  НЕТ. Класс без свойств.

================================================================
МЕТОД html(visuotag $vt, visuometa $meta) : string
================================================================

ШАГИ
  1. $head = $vt->root()->find('head')
     Если найден — $head->meta($meta)
       Что делает visuotag::meta(visuometa):
         append($meta->as_tag())   ← собрать meta-дерево и вставить
     В результате в <head> попадут:
       <title>…</title>
       <link rel="stylesheet" …>  ← из visuolink_css
       <link rel="icon" …>        ← favicon
       <script src="…">…</script> ← из visuolink_js

  2. $vt->prepare()
     Запускает хуки для узлов visuoelement / visuoel / visuostruct:
       prepare_visuoelement()
       prepare_visuoel()
       prepare_visuostruct()
     То есть visuoel-элементы «дорисовываются» в дерево:
       vt_start вставляется в children соответствующего узла.

  3. $vt->release()
     Рекурсивный HTML-рендер. При этом <head> уже наполнен meta,
     а visuoel-узлы — своими vt_start.

  4. return $vt->final()
     final() = root()->release().
     Отдаёт готовую строку.

ВАЖНО ПРО ПОРЯДОК
  meta вставляется ДО prepare, чтобы meta-элементы (title/link/script)
  тоже прошли prepare (на случай, если в них есть visuoel).
  Хотя visuometa/visuolink — чистый visuotag, prepare для них no-op.

================================================================
ЗАМЕЧАНИЯ
================================================================
1. Класс stateless — намеренно. Легко тестируется:
     $render = new visuorender();
     $html = $render->html($vt, $meta);

2. Если в дереве нет <head> — meta не вставится. Схемы
   (alliasscheme_*) всегда создают <head class="cl_head">,
   так что на практике он есть.
   Но если кто-то заменил дерево вручную и забыл head — meta
   потеряется молча.

3. prepare() не идемпотентен в смысле повторных вызовов?
   visuotag::prepare() обходит дерево и для visuoelement/visuoel
   проверяет ->init (флаг). После первого prepare ->init=true,
   повторный вызов не продублирует. Ок.

4. release() тоже вызывается один раз в html(). Если кто-то
   потом ещё раз вызовет $vt->release() — вернёт то же самое
   (дерево уже готово).

5. Нет отладочного вывода — если нужно посмотреть дерево,
   используйте visuotag::releasetree() (см. debug_attach в 43).

ПОЛНЫЙ ЦИКЛ РЕНДЕРА (сводно)
================================================================
  main::release()
    → render::release()
        → visuorelease::final($log, $debug)
            → $struct = main->visuostruct->current()
            → if visuostruct_html: visuopage->apply($struct)
            → debug_attach($log, $debug)     ← панель в dt_debug
            → print visuorender->html($visuotag, $visuometa)
                 head->meta($meta)            ← meta в <head>
                 vt->prepare()                ← хуки visuoel
                 vt->release()                ← HTML
                 return vt->final()           ← строка
