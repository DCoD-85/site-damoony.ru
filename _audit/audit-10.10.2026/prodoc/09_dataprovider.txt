================================================================
09_DATAPROVIDER — dataprovider.php
Фасад домена: держит фасады всех аллиасов.
================================================================

ПОДКЛЮЧАЕТСЯ ИЗ: main::logic()  → new \damoony\dataprovider($main)
РОЛЬ:            Единая точка входа к данным любого аллиаса.
                 Автоподхват: сканирует allias/*/dataprovider/dataprovider.php
                 и создаёт их фасады.

ИСПОЛЬЗОВАНИЕ
  $main->dataprovider->current->…  ← текущий аллиас (ярлык)
  $main->dataprovider->visuo->…    ← явно
  $main->dataprovider->login->…    ← чужой аллиас

================================================================
СВОЙСТВА
================================================================
  main    : main
  www     : ?\damoony\www\dataprovider
  login   : ?\damoony\login\dataprovider
  visuo   : ?\damoony\visuo\dataprovider
  current : mixed   — ссылка на один из *выше

================================================================
МЕТОДЫ
================================================================

__construct( main )
    autoload()
    set_current()

private autoload( )
    $allias_dir = __DIR__ / allias
    foreach glob($allias_dir . '/*', GLOB_ONLYDIR):
      $allias_name = basename($dir)
      $file = $dir . '/dataprovider/dataprovider.php'
      если файла нет — continue
      include_once $file
      $class = '\damoony\<allias_name>\dataprovider'
      если класс не объявлен — continue
      $this->{<allias_name>} = new $class($this->main)

private set_current( )
    $current = main_settings->allias_accepted()
    если null/'' — return
    если свойства с таким именем нет — return
    $this->current = $this->{<current>}

ЗАМЕЧАНИЯ
- Имена свойств (www/login/visuo) жёстко в классе, а автолоад
  может создать и другие. Динамическое свойство, не объявленное
  в классе → PHP 8.2+ warning. Решение: добавить __get/__set
  или явно перечислить все возможные аллиасы.
- set_current работает по имени класса через allias_accepted() —
  связь с site.config. Если аллиас есть в alliases_real, но нет
  в alliases_available, current останется null.
- include_once + class_exists без проверки на повторное new —
  при повторном вызове autoload() создаст второй экземпляр.
  Сейчас autoload() вызывается один раз, но лучше проверять
  isset($this->{<name>}).
