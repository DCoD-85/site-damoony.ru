ЧАСТЬ 1. БАЗА — группа и элемент группы
================================================================

A. visuoel_group extends visuoel
----------------------------------------------------------------
$css_class = 'group'

make_default_data() → visuoel_group__data
build()             → <div class="group"> (своя обёртка)
                      vt_start = vt_end = div

Это база для всех групп (block, message, input, button, field,
form, tabs, table). Конкретные группы переопределяют $css_class
или build().

visuoel_group__data extends visuoel__data  — пустой (пока).

B. visuoel_group_element extends visuoel
----------------------------------------------------------------
$css_class = 'element'

make_default_data() → visuoel_group_element__data
build()             → <div class="element"> (своя обёртка)
                      vt_start = vt_end = div

data() → __data as visuoel_group_element__data

visuoel_group_element__data extends visuoel__data
  readonly : bool = false
  disabled : bool = false
  — общие флаги для всех элементов группы.

ВАЖНО
  База рисует <div class="element">. Конкретные элементы обычно
  переопределяют build() и рисуют «настоящий» тег (<input>,
  <button>, <form>). Но если не переопределить — получится
  div-заглушка.

ЧАСТЬ 2. BLOCK — визуальный блок с текстом/html
================================================================

A. visuoel_block extends visuoel_group
----------------------------------------------------------------
singleton = false    ← каждый block() в родителе даёт новый блок
build() → прозрачный vt_start = vt_end = new visuotag

ФАБРИКИ
  text($data=null)  → visuoel_block_text
  html($data=null)  → visuoel_block_html

Каждая: new visuoel_block_<type>($this, $data as ?__data),
        elements[] = $el, return $el.

visuoel_block__data extends visuoel_group__data — пустой.

B. visuoel_block__element extends visuoel_group_element  (abstract)
----------------------------------------------------------------
make_default_data() → visuoel_block__element__data

build()
  vt = <tag class="<css_class>">
  if data.content !== '' → vt->content(htmlspecialchars(content))
  vt_start = vt_end = vt

То есть базовый блок — это обёртка <tag class="css_class">текст</tag>.

Конкретные подтипы задают $tag и $css_class.

visuoel_block__element__data extends visuoel_group_element__data
  content : string = ''
  set(string $content) : $this

C. visuoel_block_text extends visuoel_block__element
   (tag/css_class: см. файл подтипа)
D. visuoel_block_html extends visuoel_block__element
   (html — обычно tag='div', без экранирования)

ЧАСТЬ 4. INPUT — группа инпутов + 14 подтипов
================================================================

A. visuoel_input extends visuoel_group
----------------------------------------------------------------
css_class = 'input'
singleton НЕ переопределён → наследует true от visuoel.
  ⚠ Необычно: в группе input singleton=true.
  Фактически значит, что повторный вызов $ve->input() вернёт
  тот же объект (пока элементы внутри добавляются через
  ->input()->text() и т.п. — они всегда создают новые).

build() → <div class="input">

ФАБРИКИ (каждая — new visuoel_input_<type>($this, $data as ?__data))
  text / hidden / password / email / file / textarea / select /
  checkbox / radio / checkbox_group / radio_group /
  submit / reset / button

GETTERS
  get_text__data / get_hidden__data / get_password__data /
  get_email__data / get_file__data / get_textarea__data /
  get_select__data / get_submit__data
      Проходят по elements, ищут первый instance нужного класса,
      возвращают ->data().
      ⚠ Нет get_radio/checkbox/reset/button__data — только эти 8.

visuoel_input__data extends visuoel_group__data — пустой.

B. visuoel_input__element extends visuoel_group_element  (abstract)
----------------------------------------------------------------
abstract input_type() : string

make_default_data() → visuoel_input__element__data

build()
  vt = <input type="<type>" ... />   (tag_closed = false)
  Добавляет только непустые атрибуты:
    id, name, value, placeholder, autocomplete, accept
    multiple, checked, required, readonly, disabled — boolean
  vt_start = vt_end = vt

visuoel_input__element__data extends visuoel_group_element__data
  # Общие поля для всех input-типов:
  id, name, value, placeholder, autocomplete, accept : string
  checked, required, multiple : bool
  rows, cols, size : int
  options : array          # для select: [value => label]
  selected : mixed         # для select/radio: string|array|null
  placeholder_option : string  # первый <option> с пустым value

  СЕТТЕРЫ (все возвращают $this):
    set($name, $value='', $placeholder='')
    id / value / placeholder / autocomplete / accept
    multiple / checked / required / readonly / disabled
    rows / cols / options / option($v, $label) / selected / size /
    placeholder_option

C. Подтипы input (по 1 файлу на тип)
  visuoel_input_text
  visuoel_input_hidden
  visuoel_input_password
  visuoel_input_email
  visuoel_input_file
  visuoel_input_textarea     — рендер <textarea>…, использует rows/cols
  visuoel_input_select       — рендер <select> с options + selected
  visuoel_input_checkbox
  visuoel_input_radio
  visuoel_input_checkbox_group
  visuoel_input_radio_group
  visuoel_input_submit
  visuoel_input_reset
  visuoel_input_button

  Каждый:
    - задаёт input_type() (или рендерит не-input тег: textarea/select)
    - может переопределять build()

ЗАМЕЧАНИЯ
1. input_type() — вход в базовый build(); конкретный подтип должен
   вернуть 'text'/'checkbox'/…, и тогда базовый build() соберёт
   <input type="...">.
2. select и textarea переопределяют build() полностью — базовый
   <input> для них не годится.
3. В visuoel_input singleton=true (наследовано) — фактически
   это не мешает, потому что фабрики внутри группы всегда создают
   новые элементы. Но если кто-то вызовет $ve->input() дважды —
   вернётся тот же объект.

ЧАСТЬ 6. FIELD — поле с обёрткой label + input + hint + error
================================================================

A. visuoel_field extends visuoel_group
----------------------------------------------------------------
singleton = false
build() → прозрачный vt_start = vt_end = new visuotag

ФАБРИКИ
  text / password / email / file / textarea / select /
  checkbox / radio / checkbox_group / radio_group
    new visuoel_field_<type>($this, $data as ?__data)

  ⚠ Нет фабрик field->submit / reset / button.
    Они есть в visuoel_field__button и вызываются отдельно.

visuoel_field__data extends visuoel_group__data — пустой.

B. visuoel_field__element extends visuoel_group_element (abstract)
----------------------------------------------------------------
abstract input_type() : string

make_input() : ?visuoel_input__element
  По умолчанию null. Подтип может вернуть конкретный input-элемент.

build_element(visuotag $box) : void
  input_el = make_input()
  if null → return
  d = data
  inp = input_el->data()
  Копирует поля из data поля в input__element__data:
    id = 'field_' . name
    name, value, placeholder, autocomplete, accept,
    required, readonly, disabled, multiple,
    rows, cols, options, selected, size, placeholder_option
  input_el->init()
  border = <div class="border-box">
  border->append(input_el->vt_start)

build()
  field = <div class="field field_<input_type>">
  box = <div class="box">
  # 1. label (если show_label && label !== '')
     <label class="field-label" for="field_<name>">
       label
       + <span class="label_comment">…</span> (если label_comment)
  # 2. element
     build_element(box)
  # 3. hint (если show_hint && hint !== '')
     <div class="hint">…</div>
  # 4. error (всегда, если error !== '')
     <div class="error">…</div>
  vt_start = vt_end = field

visuoel_field__element__data extends visuoel_input__element__data
  # Наследует все поля input__element__data
  label, label_comment, hint, error : string
  show_label, show_hint : bool = true
  label($l, $comment='') / hint($h) / error($e)
  hide_label() / hide_hint()

C. visuoel_field__button extends visuoel_field__element (abstract)
----------------------------------------------------------------
abstract make_button() : visuoel_button__element

make_default_data() → visuoel_field__button__data

build()
  field = <div class="field field_<input_type>">
  box   = <div class="box">
  # 1. label — но не <label>, а <div class="field-label">
     (потому что у кнопки нет input для связки)
  # 2. border-box + кнопка
     btn = make_button()
     Копирует из data: text, name, value, css_class, disabled
     btn->init()
     border->append(btn->vt_start)
  # 3. hint (если show_hint)
  # 4. error (всегда, если error)

visuoel_field__button__data extends visuoel_field__element__data
  text, css_class : string
  text($t) / css_class($c)

D. Подтипы field
  visuoel_field_text / _password / _email / _file / _textarea /
  _select / _checkbox / _radio / _checkbox_group / _radio_group
     — наследуют visuoel_field__element, реализуют make_input().

  visuoel_field_submit / _reset / _button
     — наследуют visuoel_field__button, реализуют make_button().

  visuoel_field_block — что-то ещё (см. отдельный файл).

ЗАМЕЧАНИЯ
1. Чекбоксы и радио переопределяют build() целиком (label оборачивает
   input), потому что структура другая.
2. Группы (checkbox_group/radio_group) рисуют свой контейнер.
3. Поля-кнопки (submit/reset/button) — через visuoel_field__button,
   а не через visuoel_field::submit().

ЧАСТЬ 8. TABS — табы
================================================================

visuoel_tabs extends visuoel_group
----------------------------------------------------------------
css_class = 'tabs'
singleton = false
vt_head, vt_body : ?visuotag

make_default_data() → visuoel_tabs__data (extends group__data, пустой)

build()
  tabs = <div class="tabs">
  head = <div class="hhead">
  body = <div class="bbody">
  vt_start = tabs
  vt_head  = head
  vt_body  = body
  vt_end   = body

init()   ← ПЕРЕОПРЕДЕЛЁН (не как у родителя)
  if init → return
  init = true
  build()

  first = true
  foreach elements:
    if ! page instanceof visuoel_tabs_page → skip
    page->init()
    if first:
      page->vt_title->attrs_class_add(' selected')
      page->vt_start->attrs_class_add(' selected')
      first = false
    vt_head->append(page->vt_title)
    vt_body->append(page->vt_start)

page($data=null) : visuoel_tabs_page
  new visuoel_tabs_page($this, $data if __data instance)
  elements[] = $el
  return $el

визуально
  div.tabs
    div.hhead   — заголовки табов
    div.bbody   — тела табов
  Первый page получает класс ' selected'.

ЧАСТЬ 9. TABLE — таблица/сетка
================================================================

visuoel_table extends visuoel_group
----------------------------------------------------------------
singleton = false
section_head / _body / _foot : ?visuoel_table_section

make_default_data() → visuoel_table__data

build()
  if data.html_mode:
    vt = <table class="visuotable_html"> + html_attrs
  else:
    vt = <div class="visuotable">
  vt_start = vt_end = vt

html_mode(bool $mode=true) : $this   — переключение режима
attr($name, $value) : $this          — доп. атрибут (только html_mode)

row()   → body()->row()              — shortcut
head()  → создать/вернуть section_head (zone='thead')
body()  → создать/вернуть section_body (zone='tbody')
foot()  → создать/вернуть section_foot (zone='tfoot')

visuoel_table__data extends visuoel_group__data
  html_mode : bool = false
  html_attrs : array = []

Два режима
  html_mode=false → div.visuotable с div.ttype.tbody / .row / .col.cols_N
  html_mode=true  → настоящая <table> с <thead>/<tbody>/<tfoot>

Подклассы (см. отдельные файлы)
  visuoel_table_section — thead/tbody/tfoot
  visuoel_table_row     — <tr> / div.row
  visuoel_table_cell    — <td> / div.col

ОБЩИЕ ЗАМЕЧАНИЯ ПО API
================================================================
1. Все группы наследуют от visuoel_group (единая база).
   Все элементы — от visuoel_group_element (единая база).

2. Каждая группа задаёт свой $css_class и (обычно) переопределяет
   build() для своей структуры.

3. Фабрики всегда создают новый элемент (кроме форм с singleton=true).
   В родителе (visuoel) — singleton=true по умолчанию; конкретные
   группы явно ставят singleton=false, чтобы давать новое при
   каждом вызове.

4. data() возвращает конкретный __data-класс (с методами).
   Установка значений — через цепочку:
     $el->block()->html()->data()->set('<p>...</p>');

5. build() — фаза 1. init() — фаза 2 (детей пришить).
   init() идемпотентен.

6. release()/show() — итоговый HTML. Обычно вызывается через
   visuotag::el($visuoel), который и вставляет vt_start в дерево.
