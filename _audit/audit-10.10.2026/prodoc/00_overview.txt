СЛОИ (снизу вверх)
================================================================

1. main (www/main.php)
   main_settings  — config/site.config, render.config, lang.config, db.secure
   main_path      — URL
   library        — url, link, language, user
   visuorelease   — рендер, meta, visuotag-контекст
   visuostruct / visuolog
   db / user / language / messages / ...

2. domain (domain.php)
   domaininfo     — имя домена + история
   подключает:
     <domain>/allias.php
     <domain>/alliaslocal.php
     <domain>/alliasglobal.php
     <domain>/alliasscheme.php
     <domain>/dataprovider.php
   domainglobal   — пустышка (см. 04)

3. allias (allias.php)
   alliasinfo
   подключает <allias>/include.php

4. alliaslocal (alliaslocal.php)
   top, bottom (left/right/center — закомментированы)

5. alliasglobal (alliasglobal.php)
   Блоки: top, left, center, right, bottom, policy, debug
   Скрипты: headers, head  (не-визуальные)
   Меню: alliasglobal_menu, alliasglobal_menu_row
   База блока: alliasblock
   База скрипта: alliasglobalscript
   Трейт filler'а: alliasglobal_filler_trait

6. alliasscheme (alliasscheme.php)
   Схемы: login, error, min, www, visuo
   Каждая — «движок» body + meta + слоты dt_*
   load() / reload()

7. dataprovider (dataprovider.php + <allias>/dataprovider/)
   Фасад домена → фасады аллиасов → базы данных.

8. algoritm (allias/<a>/algoritm/*)
   Фреймворк роутинга URL → классы страниц.
   algoritm_ (база), algoritmdata_ (пакет параметров).
   visuo/algoritm/algoritm.php — корневой алгоритм аллиаса.
   algoritm_lang_* — страницы.

9. user (allias/visuo/user.php и т.п.)
   Замена базового $main->user на allias-специфичную версию.
   Работает через dataprovider_user.

ПОТОК
================================================================
  index.php
    → constants.php + included.php
    → main.php (main_settings + main)
    → main->main() = path → init → logic → savedata → release
      init    : подсистемы, language, logic_ver, user->authorized
      logic   : domain → domainglobal → dataprovider →
                allias → alliaslocal → alliasglobal → alliasscheme →
                algoritm(algoritm->clear/start/debug)
      release : scripts->run() → render->release()

КОНВЕНЦИИ ФАЙЛОВ
================================================================
  <name>.php              — тонкий класс
  <name>.data.php         — данные (include из класса)
  <name>_<allias>.php     — filler аллиаса (тонкий)
  <name>_<allias>.data.php — данные filler'а
  _template_block.php     — эталон блока
  _template_script.php    — эталон скрипта
  include.php             — точка входа аллиаса
  algoritm/<page>.php     — страничный алгоритм

FILLER'Ы (alliasglobal)
================================================================
Включаются через main_settings->fillers:
  fillers[<domain>][<allias>][<block>] = true
Если true — ищется <block>/<block>_<allias>.php + data.
Если false/нет — работает <block>.data.php.

Реализованные filler'ы: top/left/center/right/bottom/policy/debug
для allias visuo и www.
