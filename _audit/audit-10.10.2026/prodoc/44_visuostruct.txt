================================================================
44_VISUOSTRUCT — visuostruct + 3 подтипа
Выбор формата финального ответа: HTML / AJAX / min-JSON.
================================================================

namespace: (глобальный)
ПОДКЛЮЧАЕТСЯ ИЗ: sources/visuo/visuo.php (шаг 14)
РОЛЬ:
  Программист (алгоритм) может выбрать, что вернуть клиенту:
    - обычный HTML (по умолчанию),
    - AJAX-ответ с набором слоёв (top/left/center/right/bottom),
    - «минимальный» JSON-ответ (для форм/AJAX-сабмитов).
  visuostruct::current() решает, какой режим активен.
  visuorelease::final() читает current()->return_type() и действует.

ФАЙЛЫ
  visuostruct.php                       — контейнер + ленивая фабрика
  visuostruct/visuostruct_html.php      — структура «HTML по умолчанию»
  visuostruct/visuostruct_ajax.php      — AJAX-ответ со слоями
  visuostruct/visuostruct_min.php       — JSON для AJAX-сабмита

================================================================
1. visuostruct — контейнер
================================================================
СВОЙСТВА
  main : ?\main
  html : ?visuostruct_html
  min  : ?visuostruct_min
  ajax : ?visuostruct_ajax

ЛЕНИВЫЕ ФАБРИКИ
  html() : visuostruct_html
    При первом вызове — include файла + new.
  min()  : visuostruct_min
  ajax() : visuostruct_ajax

CURRENT
  current() : ?object
    Приоритет:
      1. min  — если создан → он
      2. ajax — иначе если создан → он
      3. html — иначе если создан → он
      4. null — если ничего не создано

СМЫСЛ
  Программист зовёт $main->visuostruct->min()->... или ajax()->...,
  чтобы переопределить формат. Если не зовёт ни один — final()
  пойдёт по ветке HTML (struct=null).

================================================================
2. visuostruct_html — HTML-режим (по умолчанию)
================================================================
СВОЙСТВА
  visuostruct : ?visuostruct
  top / left / center / right / bottom : null|visuotag|false
    null  — не переопределять (использовать как обычно)
    false — отключить блок
    visuotag — заменить блок
  meta : ?visuometa

МЕТОДЫ
  return_type() : string  → 'html'

  set($top=null, $left=null, $center=null, $right=null, $bottom=null) : $this
    Устанавливает только не-null значения (null игнорируется).

  off(string $block) : $this
    property_exists → $this->{$block} = false
    То есть «выключить» конкретный блок (top/left/...).

РОЛЬ
  Программист может переопределить часть блоков или отключить.
  Visuorelease::final() в HTML-ветке вызывает
  main->visuopage->apply($struct) — visuopage разбирает эти
  переопределения и подставляет в дерево (см. 45).

ЗАМЕЧАНИЯ
- visuostruct_html НЕ имеет as_json — только как контейнер
  переопределений. Поэтому final() для него идёт общим HTML-путём.
- off() через property_exists — если передать некорректное имя,
  молча ничего не сделает.
- meta() — метод отсутствует, но поле meta есть. Установка
  извне.

================================================================
3. visuostruct_ajax — AJAX-ответ со слоями
================================================================
СВОЙСТВА
  visuostruct : ?visuostruct
  error       : bool = false
  address     : ?visuostruct_ajax_address
  header      : ?visuostruct_ajax_header
  top/left/center/right/bottom : ?visuostruct_ajax_layer (5 подклассов)

ФАБРИКИ (ленивые, через ??=)
  address()  : visuostruct_ajax_address
  header()   : visuostruct_ajax_header
  top()      : visuostruct_ajax_top
  left()     : visuostruct_ajax_left
  center()   : visuostruct_ajax_center
  right()    : visuostruct_ajax_right
  bottom()   : visuostruct_ajax_bottom

return_type() : string  → 'json'

as_json() : string
  Собирает:
    {
      "error": bool,
      "address": "…",
      "layers": {
        "header": <html-string>,
        "top":    {"layer":"dt_top",    "html":"…"},
        "left":   {"layer":"dt_left",   "html":"…"},
        "center": {"layer":"dt_center", "html":"…"},
        "right":  {"layer":"dt_right",  "html":"…"},
        "bottom": {"layer":"dt_bottom", "html":"…"}
      }
    }
  json_encode + JSON_UNESCAPED_UNICODE; при ошибке → '{}'.

ЗАМЕЧАНИЯ
- address и header — специальные (без layer-обёртки).
- Слои top/left/center/right/bottom — возвращают массив
  {layer: '<dt_имя>', html: '…'}. То есть фронт знает, в какой
  DOM-узел (div.dt_top и т.д.) вставлять этот HTML.

================================================================
4. visuostruct_ajax — внутренние классы
================================================================

visuostruct_ajax_element (abstract)
  visuostruct, visuostruct_ajax
  __construct(visuostruct_ajax)

visuostruct_ajax_address
  address : ?string
  set(address)
  astag() / release() : ?string
  — простой URL текущей страницы.

visuostruct_ajax_header
  visuotag : ?visuotag
  set($vt)
  astag() : ?visuotag
  release() : ?string   — release()->root()->release()
  — HTML без layer-обёртки.

visuostruct_ajax_layer (abstract)
  abstract layer() : string     — имя DOM-слоя (dt_top и т.д.)
  visuotag : ?visuotag
  set($vt)
  astag() : ?visuotag
  release() : ?array
    {
      'layer' => layer(),
      'html'  => visuotag->root()->release()
    }
  Если visuotag === null → return null.

Подклассы-слои (только layer()):
  visuostruct_ajax_top     → 'dt_top'
  visuostruct_ajax_left    → 'dt_left'
  visuostruct_ajax_center  → 'dt_center'
  visuostruct_ajax_right   → 'dt_right'
  visuostruct_ajax_bottom  → 'dt_bottom'

================================================================
5. visuostruct_min — минимальный JSON (AJAX-сабмит)
================================================================
СВОЙСТВА
  visuostruct : ?visuostruct
  error    : ?visuostruct_min_error
  messages : ?visuostruct_min_messages
  release  : ?visuostruct_min_release
  form     : ?visuostruct_min_form
  referer  : ?visuostruct_min_referer

ЛЕНИВЫЕ ФАБРИКИ
  error()    : visuostruct_min_error
  messages() : visuostruct_min_messages
  release()  : visuostruct_min_release
  form()     : visuostruct_min_form
  referer()  : visuostruct_min_referer

return_type() : string  → 'json'

as_json() : string
  {
    "error":    false,
    "messages": "",       ← HTML-строка
    "release":  null,     ← объект {html, layer, popup, ...}
    "form":     null,     ← объект {reset, redirect, redirect_time}
    "referer":  null      ← URL
  }

РОЛЬ
  Используется для AJAX-сабмита форм: сообщения, действия
  с формой (reset/redirect), referer.

================================================================
6. visuostruct_min — внутренние классы
================================================================

visuostruct_min_element (abstract)
  visuostruct, visuostruct_min
  __construct(visuostruct_min)

visuostruct_min_error
  error : bool = false
  set(bool)
  release() : bool

visuostruct_min_messages
  visuotag : ?visuotag
  set($vt)
  release() : string — release()->root()->release(), или ''

visuostruct_min_release
  html : ?visuotag
  layer : string
  popup / popup_back / popup_navigate : bool
  set($html, $layer='', $popup=false, $popup_back=false, $popup_navigate=false)
  release() : array
    {
      'html': '<html-string>',
      'layer': '<layer>',
      'popup': bool,
      'popup_back': bool,
      'popup_navigate': bool
    }
  html_str получается через root()->prepare() + root()->release()
  (prepare — фаза хуков visuotag: см. 38).

visuostruct_min_form
  reset : bool
  redirect : ?string
  redirect_time : ?int
  set(reset, redirect, redirect_time)
  release() : array

visuostruct_min_referer
  referer : ?string
  set($referer)
  release() : ?string
    Если не задан — берёт из $_SERVER['HTTP_REFERER'].

================================================================
7. ПОТОК В VISUORELEASE::FINAL (сводно)
================================================================
  $struct = main->visuostruct?->current()

  Случай A: $struct = null
    → HTML-рендер целиком (обычный путь).

  Случай B: $struct = visuostruct_html
    → return_type() = 'html'
    → visuopage->apply($struct)   — переопределения блоков
    → HTML-рендер.

  Случай C: $struct = visuostruct_ajax
    → return_type() = 'json'
    → header json
    → print as_json()   — БЕЗ рендера HTML.

  Случай D: $struct = visuostruct_min
    → return_type() = 'json'
    → print as_json().

================================================================
8. ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ
================================================================

HTML с переопределением top:
  $s = $main->visuostruct->html();
  $s->set(top: $custom_vt);
  // final → HTML, top заменён.

HTML с отключением left:
  $main->visuostruct->html()->off('left');

AJAX со слоями:
  $a = $main->visuostruct->ajax();
  $a->center()->set($vt_center);
  $a->top()->set($vt_top);
  // final → JSON: {layers: {center: {layer:'dt_center', html:...}, ...}}

Min-JSON для формы:
  $m = $main->visuostruct->min();
  $m->messages()->set($vt_messages);
  $m->form()->set(reset: true);
  // final → JSON: {error:false, messages:'<html>', form:{reset:true,...}}

================================================================
9. ЗАМЕЧАНИЯ / БАГИ
================================================================
1. current() приоритет: min > ajax > html.
   Если программист случайно создал и min, и ajax — вернётся min,
   без предупреждения.

2. visuostruct_html не имеет as_json() — final() для него идёт
   HTML-веткой. Логично, но неочевидно по имени класса.

3. off($block) через property_exists: в классе нет свойства
   'header', так что $html->off('header') ничего не сделает.
   Работает только для top/left/center/right/bottom.

4. visuostruct_min_release::release() вызывает root()->prepare() —
   это запускает хуки (visuoelement/visuoel) перед рендером.
   Это важно: без prepare содержимое visuoel не попадёт в HTML.

5. Все фабрики в ajax/min — ??= (lazy). Созданный объект
   переиспользуется. То есть $a->center() дважды вернёт тот же
   объект.

6. Структуры не сериализуются в кеш — просто поля в памяти
   на время запроса.

7. visuostruct_ajax::as_json() собирает header и слои через
   release(). Если слой не задан — вернёт null (в JSON это
   ключ со значением null). Front-end должен это учитывать.

8. visuostruct_min::referer::release() — если свойство null,
   берёт HTTP_REFERER. Удобно, но неявно.

9. Поля visuostruct_ajax_layer::release() — массив {layer, html}.
   Слои-обёртки (top/left/...) различаются только именем layer.
   Ок, но можно было бы вынести константу.

10. Нет as_json у visuostruct_html — если фронту нужен HTML
    «декларативно», надо смотреть на visuopage (45).
