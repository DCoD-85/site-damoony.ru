================================================================
03_MAIN — www/main.php
Ядро системы: класс main + main_settings + main_path.
================================================================

ПУТЬ:  www/main.php
РОЛЬ:  Центральный оркестратор. Хранит все подсистемы,
       определяет порядок их инициализации и запускает рендер.
       Здесь же — main_settings (обёртка над config/*.config)
       и main_path (разбор URL).

================================================================
0. ВЕРХ ФАЙЛА
================================================================
  use damoony\{www, login};
  → подтягиваются неймспейсы домена damoony.ru,
    но namespace объявлен не здесь (файл — глобальный).

================================================================
1. class main
================================================================

ССЫЛКИ НА ПОДСИСТЕМЫ (public свойства):
  main_settings  — конфиг
  main_path      — разбор URL

  База (sources):
    render, user, blacklist, vardump, log, core, db,
    library, system, language, messages, gmod, mod, visuopage

  Домен:
    domain, domainglobal

  Аллиас:
    allias, alliasglobal, alliaslocal, alliasscheme, dataprovider

  Алгоритм:
    algoritm_ (устаревший?), algoritm (актуальный),
    algoritm_class[], subalgoritm

  Visuo:
    visuorelease, visuostruct, visuolog

  Прочее:
    release_min (string) — префикс/флаг минимального рендера

МЕТОДЫ
----------------------------------------------------------------

__construct( ?main_settings )
    Принимает уже готовый main_settings (передаётся из index.php)
    либо создаёт сам.
    main_settings->main($this) — обратная привязка.

path( ?string $url = null )
    Ленивая инициализация main_path + set($url).

init( )   ← ФАЗА 1: поднять подсистемы
    1. include_once sources/include.php
       (все классы движка: render, user, library, db, ...)
    2. Ленивые: visuorelease, visuopage, visuostruct, render
    3. new core, user, blacklist, log, vardump, db,
       library, language, messages, gmod, mod
    4. main_settings->init()    ← читает config/*.config
       main_settings->set('connect_type', 'http://')
    5. language->load()->init()
    6. include_once logic/<logic_ver>/include.php
       (logic_ver = 'alpha.0.0' из настроек)
    7. gmod->init(), blacklist->init()
    8. db->open('login_damoony'), user->authorized()

logic( )   ← ФАЗА 2: домен + аллиас + алгоритм
    Динамические классы по namespace домена ($static_domain):
      new domain, domainglobal
      new \damoony\dataprovider         (фасад)
      new \damoony\allias
      new \damoony\alliaslocal
      new \damoony\alliasglobal
      new \damoony\alliasscheme
      new \<domain>\<allias>\algoritm    ← algo текущего аллиаса
      → algoritm->clear(); start(); debug()

    ВАЖНО: namespace домена берётся из main_settings->domain_accepted(false)
           (= 'damoony'), а имя аллиаса — из allias_accepted().

savedata( )
    language->savedefaults()   — сохранение пользовательских языковых предпочтений.

release( $log = false , $debug = false )
    ФАЗА 3: финальный рендер.
      1. Прогон alliasglobal->scripts[*]->run()
         (не-визуальные скрипты: headers, head)
      2. render->release($log, $debug)

main( ?string $address = null )
    Единая точка запуска: path → init → logic → savedata → release.

redirect( ?string $address )
    Облегчённая версия main() БЕЗ init и release:
      path → main_settings->init → logic
    (используется для внутренних редиректов на другой аллиас)

main_error( string $title , string $message )
    Минимальный HTML-die(). private.

is_guest( ) : bool
    true если user === null ИЛИ user->is_guest().
    Гарантирует, что не падает, если user не инициализирован.

is_auth( ) : bool
    ! is_guest().

================================================================
2. class main_path
================================================================
  Хранит domain + url, разобранные из строки.

  set( ?string $path = null )
      Если $path null — берёт REQUEST_SCHEME://SERVER_NAME/REQUEST_URI.
      Регуляркой раскладывает URL:
        $domain = $returnData[4]   (хост без протокола)
        $url    = $returnData[0]   (полный URL)
  get_domain(), get_url() — аксессоры.

================================================================
3. class main_settings
================================================================
  Обёртка над config/*.config, доступ через свойства.

СВОЙСТВА (важные):
  domain_real_name : string      — 'damoony.ru' (или из domains_real)
  allias_real_name : string      — 'visuo' / 'www' / ...
  language         : string      — 'ru-ru' | 'en-en' | 'ch-ch'
  render           : string      — 'visuo'
  logic            : string      — 'alpha.0.0'
  skin             : string      — 'default' (из cookie)
  skin_allias      : string      — обычно 'www'
  connect_type     : string      — 'http://' | 'https://'
  render_engine    : array       — ['default' => 'algoritm']

  domains_real        : array   — из site.config
  domains_available   : array   — из site.config
  alliases_real       : array   — из site.config
  alliases_available  : array   — из site.config
  fillers             : array   — из site.config (для filler-блоков)

__construct( ?main $main , $settings )
    Значения по умолчанию: render='visuo', language='ru-ru', skin='default'.
    Приоритет: cookie > $settings.

init( )
    Загружает 4 конфига:
      config/site.config
      config/render.config
      config/lang.config
      secure/db.secure
    Затем:
      - язык: URL (первый сегмент) приоритетнее cookie;
      - domain_real_name  = domains_real[ $url_allias[0] ]
      - allias_real_name  = alliases_real[ domain ][ $url_allias[1] ?? '' ]
      - skin_allias       = allias_real_name

loadExternalConfig( string $path )
    Универсальный JSON-лоадер: читает файл → json_decode → для каждого
    ключа, если property_exists($this, key) → присваивает.
    Тихо игнорирует отсутствующий/битый файл.

main( main $main )
    Обратная привязка $this->main.

domains( string $name )
    Lookup domains_real[$name] ?: null.

alliases( string $name )
    ПУСТОЙ метод — заглушка (когда-то фильтровал alliases_*).

domain_accepted( bool $full = true )
    Если domains_available[domain_real_name] → возвращает domain_real_name,
    иначе null. При $full = false усекает '.ru' → 'damoony'.

allias_accepted( )
    Возвращает allias_real_name, если он есть в alliases_available[domain],
    иначе null.

engine( ) : string
    Имя движка рендера для текущего аллиаса, fallback — 'algoritm'.

default( $lang , $render , $skin )
    Установка дефолтов + connect_type = 'https://'.

set( string $var , string $val , string $convert = 'string' )
    Прямая запись в свойство. $convert НЕ используется — мёртвый параметр.

get( string $var )
    Прямое чтение свойства.

skin( string $option )
    'skin'   → $this->skin
    'allias' → $this->skin_allias

================================================================
4. ПОТОК ЦЕЛИКОМ (сводка)
================================================================
  index.php
    new main_settings()
    new main( $main_settings )
    main->main()
      ├─ path()       → main_path::set($_SERVER)
      ├─ init()       → все подсистемы + логика alpha.0.0
      ├─ logic()      → domain → alliasglobal → algoritm
      ├─ savedata()   → language
      └─ release()    → scripts->run() + render->release()

================================================================
5. ЗАМЕЧАНИЯ / БАГИ
================================================================
1. `use damoony\{www, login};` — импорт неймспейсов, но они
   нигде явно не используются в этом файле (магия через
   динамические классы). Может ввести в заблуждение.
2. `public \algoritm_ $algoritm_;` и `public \algoritm_ $algoritm;`
   — оба типа \algoritm_, но $algoritm_ нигде не инициализируется.
3. `main_settings::set()` параметр $convert не применяется.
4. `main_settings::alliases()` — пустой.
5. `main_settings::init()` создаёт `$v = new visuotag()` и не использует.
6. `main::main_error()` — private, но не вызывается в этом файле.
7. `main::logic()` использует `$static_allias` в new (<ns>\<allias>\algoritm),
   но при этом `$static_allias` = allias_accepted() (реальное имя),
   не URL-сегмент. Ок, просто отметить.
8. `main_path::set()` — если $path пуст и $_SERVER['REQUEST_SCHEME']
   не установлен (CLI), будет notice.
9. `domain_accepted()` — `$this->domains_available[$this->domain_real_name]`
   без ?? — notice при отсутствии ключа.
10. `main_settings::__construct` — дефолтный массив $settings
    содержит render/language/skin, но при передаче только части
    массива, остальные ключи не добиваются → notice.
