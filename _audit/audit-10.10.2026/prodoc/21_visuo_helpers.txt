================================================================
21_VISUO_HELPERS — allias/visuo/helpers.php
Утилиты visuo (namespace damoony\visuo, глобальные функции).
================================================================

ПОДКЛЮЧАЕТСЯ ИЗ: include.php (visuo)
РОЛЬ: маленькая библиотека — escape, CSRF, slug, время, redirect, json.

ФУНКЦИИ
----------------------------------------------------------------

h( ?string ) : string
    htmlspecialchars((string)$s, ENT_QUOTES, 'UTF-8')

csrf_token() : string
    session_start() при необходимости.
    $_SESSION['visuo_csrf'] — генерит 32-байтный токен, если нет.

csrf_field() : string
    HTML input[type=hidden][name=_csrf] с h(csrf_token()).

csrf_check() : bool
    true если не POST.
    Иначе — hash_equals(cookie, POST['_csrf']).

slugify( string ) : string
    mb_strtolower → транслит RU→EN (полная таблица) → [a-z0-9-] → trim '-'.
    Если получилось пусто — 'item-<md5-8>'.

time_local( string $utc , string $tz = 'Europe/Moscow' ) : string
    UTC → локальная зона, формат 'd.m.Y H:i'.
    Если $tz невалидный — fallback Europe/Moscow.
    try/catch на исключение DateTime.

now_utc() : string
    gmdate('Y-m-d H:i:s').

redirect( string $url , int $code = 307 ) : never
    http_response_code + header Location + exit.

json_response( array $data , int $code = 200 ) : never
    http_response_code + header json + echo + exit.

langs_available() : array
    ['ru-ru','en-en','ch-ch']

lang_default() : string
    'ru-ru'

ЗАМЕЧАНИЯ
- csrf_token() использует @session_start() — подавление warning,
  если сессия уже активна.
- slugify: транслит кириллица→латиница; остальное → '-'.
- redirect по умолчанию 307 (сохраняет метод).
