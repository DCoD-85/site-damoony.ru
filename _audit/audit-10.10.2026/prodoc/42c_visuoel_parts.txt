42C_VISUOEL_PARTS — все подтипы visuoel/*
Сжатый обзор. Большинство — тривиальные подтипы.
================================================================

ОБЩАЯ СХЕМА ПОДТИПА
  class visuoel_<group>_<type> extends visuoel_<group>__element
    protected function <kind>_type() : string { return '<type>'; }
    protected function make_default_data() : visuoel__data
        → new visuoel_<group>_<type>__data($this)

  class visuoel_<group>_<type>__data extends visuoel_<group>__element__data {}

  Где <kind> = input / message / button.
  Тело пустое, вся специфика — в родителе + возвращаемый type.

================================================================
ЧАСТЬ 1. BLOCK — 2 подтипа
================================================================

visuoel_block_text
  extends visuoel_block__element
  $tag='div', $css_class='block_text'
  build() — как у родителя (экранирование через htmlspecialchars).
  Данные: visuoel_block_text__data (пустой).

visuoel_block_html
  extends visuoel_block__element
  $tag='div', $css_class='block_html'
  ПЕРЕОПРЕДЕЛЯЕТ build() — БЕЗ htmlspecialchars.
  ⚠ Сырой HTML. Опасно для пользовательских данных.
  Данные: visuoel_block_html__data (пустой).

ЧАСТЬ 2. MESSAGE — 4 подтипа
================================================================

Все тривиальны:
  visuoel_message_info       — message_type() = 'info'
  visuoel_message_success    — 'success'
  visuoel_message_warning    — 'warning'
  visuoel_message_error      — 'error'

Каждый: extends visuoel_message__element + своя __data (пустая).
build() — базовый:
  <div class="message message_<type>">текст</div>

ЧАСТЬ 3. INPUT — 14 подтипов
================================================================

ТРИВИАЛЬНЫЕ (просто input_type → 'text'/'...')
  visuoel_input_text       — 'text'
  visuoel_input_hidden     — 'hidden'
  visuoel_input_password   — 'password'
  visuoel_input_email      — 'email'
  visuoel_input_file       — 'file'
  visuoel_input_submit     — 'submit'
  visuoel_input_reset      — 'reset'
  visuoel_input_button     — 'button'
  visuoel_input_checkbox   — 'checkbox'
  visuoel_input_radio      — 'radio'
  visuoel_input_textarea   — 'textarea'    (см. ниже)
  visuoel_input_select     — 'select'      (см. ниже)

С ПЕРЕОПРЕДЕЛЁННЫМ build()
----------------------------------------------------------------
visuoel_input_textarea
  input_type() = 'textarea'
  build() переопределён:
    <textarea id name placeholder autocomplete rows cols
              required readonly disabled>value</textarea>
    value экранируется.
  rows/cols/size берутся из visuoel_input__element__data.

visuoel_input_select
  input_type() = 'select'
  build() переопределён:
    <select id name autocomplete size multiple required readonly disabled>
    placeholder_option → <option value="">label</option> (первым)
    foreach options: <option value selected?>label</option>
    selected — строка или массив (тогда несколько).
  value опций добавляется через attrs_add(value, add_empty=true).

С ГРУППОЙ
----------------------------------------------------------------
visuoel_input_checkbox_group
  build() → <div class="options"> с N чекбоксами внутри.
  name принудительно с суффиксом '[]'.
  id = 'field_' . rtrim(name, '[]') . '_' . value.
  selected — массив (сравнение строгое по строкам).
  Пустое name или options=[] → пустой <div class="options">.

visuoel_input_radio_group
  build() → <div class="options"> с N radio внутри.
  selected — одно значение (первое из массива, если массив).
  name без '[]'.
  id = 'field_' . name . '_' . value.

ВСЕ input-подтипы имеют свою пустую __data.

ЧАСТЬ 4. BUTTON — 3 подтипа
================================================================
  visuoel_button_submit — button_type() = 'submit'
  visuoel_button_reset  — 'reset'
  visuoel_button_button — 'button'

build() — базовый:
  <button type="<type>" class="button button_<type>" name value ...>text</button>
  Только непустые name/value; disabled — если true.

__data у всех пустые.

ЧАСТЬ 5. FIELD — 13 подтипов
================================================================

A. TEXT-LIKE (element с одним input)
----------------------------------------------------------------
  visuoel_field_text      — input_type='text',     make_input → visuoel_input_text
  visuoel_field_password  — 'password',            input_password
  visuoel_field_email     — 'email',               input_email
  visuoel_field_file      — 'file',                input_file
  visuoel_field_select    — 'select',              input_select
  visuoel_field_textarea  — 'textarea',            input_textarea

  Все: extends visuoel_field__element, реализуют make_input().
  build() — базовый (label + border-box + hint + error).

B. CHECKBOX / RADIO (переопределён build)
----------------------------------------------------------------
visuoel_field_checkbox
  input_type() = 'checkbox'
  make_input() → visuoel_input_checkbox
  build() переопределён:
    <div class="field field_checkbox">
      <div class="box">
        <label class="field-label">
          <span class="border-box"><input type="checkbox"></span>
          <span class="field-name">label</span>
        </label>
        <div class="hint">…</div>
        <div class="error">…</div>
      </div>
    </div>
  value по умолчанию '1' если пусто.
  id = 'field_' . rtrim(name,'[]') . (name ends '[]' ? '_'.value : '')

visuoel_field_radio
  input_type() = 'radio'
  make_input() → visuoel_input_radio
  build() — как checkbox, но:
    id = 'field_' . name . '_' . value (всегда суффикс value)
    value не дефолтится.

C. GROUPS (контейнеры для N-детей)
----------------------------------------------------------------
visuoel_field_checkbox_group
  input_type() = 'checkbox_group'
  build():
    <div class="field field_checkbox_group">
      <div class="box">
        <div class="field-label">…</div>          (заголовок группы)
        <div class="options"></div>                ← vt_end
        <div class="hint">…</div>
        <div class="error">…</div>
      </div>
    </div>
  vt_end = <div class="options">  — сюда пришиваются дочерние
  visuoel_field_checkbox (или что угодно).

visuoel_field_radio_group
  Аналог, css_class/input_type = 'radio_group'.

D. FIELD-BLOCK (обёртка над текстом/HTML)
----------------------------------------------------------------
visuoel_field_block
  input_type() = 'block'
  НЕ наследует visuoel_field__element::build_element (там input).
  build() свой:
    <div class="field field_block">
      <div class="box">
        <label class="field-label">…</label>        (если label)
        <div class="field-content">…</div>
        <div class="hint">…</div>                    (если hint)
        <div class="error">…</div>                   (если error)
      </div>
    </div>

  __data:
    content : string
    is_html : bool = false
    text(string) — с экранированием
    html(string) — как есть

  Используется:
    - в ячейке таблицы (visuoel_table_cell::set/html оборачивают
      в field_block автоматически);
    - в форме для статичного текста.

E. FIELD-КНОПКИ (обёртки над button)
----------------------------------------------------------------
visuoel_field_submit
  input_type() = 'submit'
  make_button() → visuoel_button_submit
  build() — от visuoel_field__button.

visuoel_field_reset
  input_type() = 'reset'
  make_button() → visuoel_button_reset

visuoel_field_button
  input_type() = 'button'
  make_button() → visuoel_button_button

__data — пустые, extends visuoel_field__button__data.

ЧАСТЬ 6. FORM — 2 подтипа
================================================================

visuoel_form_form extends visuoel_group_element
  $tag='form', $css_class='form_form'

  build():
    <form action name method enctype [class]>
      [<div class="form_title">title_text</div>]
      <div class="form_body"></div>       ← vt_end
    </form>
  vt_start = <form>
  vt_end   = <div class="form_body">

  data (visuoel_form_form__data):
    form_name        = 'form'
    form_method      = 'post'
    form_action      = ''
    form_enctype     = 'application/x-www-form-urlencoded'
    form_jquery      = false   → data-form-jquery
    form_data_jquery = ['on'=>true,'layerto'=>'load_result'] → data-load
    title_text       = ''
    form_class       = ''

  set(name, method='POST', action='', enctype='...', jquery=false, title='', class='')
    Метод нормализуется:
      'get'  → enctype='get/html'
      'post' → enctype='application/x-www-form-urlencoded'
      'file' → method='POST', enctype='multipart/form-data'
      иначе  → enctype из аргумента

  fieldset($data=null) : visuoel_form_fieldset
    new fieldset + elements[]

visuoel_form_fieldset extends visuoel_group_element
  $tag='fieldset', $css_class='form_fieldset'
  build():
    <fieldset class="form_fieldset">
      [<legend>legend</legend>]
    </fieldset>
  data: legend : string, set(legend)

ЧАСТЬ 7. TABS_PAGE
================================================================

visuoel_tabs_page extends visuoel_group_element
  $css_class = 'tab_page'
  vt_title : ?visuotag

  build():
    $id = 'tab_' . spl_object_id($this)

    title = <span class="tab_title" data-tab-target="<id>"
                  onclick="visuotabs_show(this)">title</span>
    vt_title = title

    page = <div class="tab_page" id="<id>">
    vt_start = vt_end = page

  Инициализацию (selected для первого) делает родитель visuoel_tabs.
  data: title : string, set(title)

  ⚠ id завязан на spl_object_id — при перезагрузке страницы меняется,
    что нормально, но при сериализации — нет.

================================================================
ЧАСТЬ 8. TABLE — 3 подтипа
================================================================

visuoel_table_section extends visuoel_group_element
  zone = 'thead' | 'tbody' | 'tfoot'
  __construct(parent, __data, zone='tbody')

  build():
    html_mode? <zone>   : <div class="ttype <zone>">
  row() : visuoel_table_row

  detect_html_mode() — идёт вверх по parent, ищет visuoel_table__data
  и возвращает её html_mode.

visuoel_table_row extends visuoel_group_element
  build():
    html_mode? <tr> : <div class="row">
  cell($width=0, $colspan=1, $rowspan=1, $inline=false) : visuoel_table_cell
    new cell + data()->width/colspan/rowspan/inline

visuoel_table_cell extends visuoel_group_element
  build() двухрежимный:
    html_mode → <td colspan rowspan style="width: N%">content</td>
                content экранируется/сырой по is_html
    div_mode  → <div class="col [extra] [colelsinline]" style="width:N%">
                  <div class="col-inside">
                    <div class="col_block"></div>   ← vt_end
                  </div>
                </div>

  set(text)  — устанавливает content + ensure_content_block()
  html(html) — content + is_html=true + ensure_content_block()
  width/colspan/rowspan/inline/col(class)

  ensure_content_block()
    Если content непусто и content_block === null:
      создаёт new visuoel_field_block()
      parent = $this
      elements[] = block
    Проставляет block->data()->content / is_html.
    То есть: текст в ячейке автоматически оборачивается в field_block.

  data:
    width : int = 0
    colspan : int = 1
    rowspan : int = 1
    inline : bool = false
    content : string
    is_html : bool = false
    class : string
    content_block : ?visuoel_field_block

  detect_html_mode() — как у section/row: идёт вверх до visuoel_table__data.

ПОРЯДОК РЕНДЕРА В ЯЧЕЙКЕ
  Порядок children = порядок вызовов:
    ->add(A)->set('text')->add(B)  → A, field_block, B
    ->set('text')->add(A)->add(B)  → field_block, A, B

================================================================
ЗАМЕЧАНИЯ
================================================================
1. Большинство подтипов — 5 строк кода: input_type / message_type /
   button_type + make_default_data. Их можно было бы генерировать
   макросом, но PHP не даёт кратко.

2. build() переопределяют только:
   - visuoel_block_html (без экранирования)
   - visuoel_input_textarea, _select, _checkbox_group, _radio_group
   - visuoel_field_checkbox, _radio, _checkbox_group, _radio_group
   - visuoel_field_block
   - visuoel_form_form, _fieldset
   - visuoel_tabs_page
   - visuoel_table_section, _row, _cell

3. detect_html_mode() в table-подтипах делает полный обход
   вверх по parent каждый раз. Это O(глубина) на каждый вызов
   (в build() — один раз, но всё же). Можно было кешировать.

4. visuoel_input::singleton = true (наследовано) — но внутри группы
   input всегда создаёт новые подтипы. singleton здесь не мешает,
   но может смущать.

5. У полей field_checkbox/radio — label оборачивает input. Это
   отличается от text/password/email/... где label идёт рядом.
   Оба варианта корректны с точки зрения CSS.

6. Шаблон «field_block для текста» используется в visuoel_table_cell
   (ensure_content_block). Также видимо применяется в поле-обёртке
   для статичного контента в форме.

7. visuoel_form_form данные: form_data_jquery — массив. Сериализуется
   в data-load через visuoattrsdata::encode (JSON).

8. Никаких экранирований html для message content в базовом build()
   (htmlspecialchars применён). Для field_block — только если is_html=false.

9. visuoel_input_select option value добавляется с add_empty=true —
   это позволяет option value="" (placeholder). Учитывать при
   чтении формы на бэкенде.

10. SELECT multiple: name без '[]' в data — надо задавать вручную.
