# 💻 Тестирование: Визуальный раннер (www/tests/)

Для быстрой проверки UI-компонентов, роутинга и базовых классов в SimplCMS используется собственный визуальный раннер тестов. Он не заменяет PHPUnit, но позволяет разработчику видеть результаты в браузере в реальном времени.

**Путь:** `www/tests/`

## Как это работает

Раннер использует сам движок `visuo` для отрисовки красивого дашборда с вкладками и зелеными/красными индикаторами.

1.  **Discovery (`Runner::discover`)** — сканирует папку `cases/` и загружает все PHP-файлы, которые возвращают массив с тестами.
2.  **Запуск (`Runner::run`)** — выполняет каждый тест (замыкание) и ловит исключения `AssertException`.
3.  **Отчет (`View`)** — собирает HTML с помощью `visuotag`/`visuoel` и выводит результат.

## Как написать свой тест

Создайте файл в папке `www/tests/cases/`, например `my_module.php`.

Структура файла:

```php
<?PHP

return [
    'title' => 'Мой модуль', // Название вкладки

    'setup' => function ( ) {
        // Код, который выполнится ОДИН РАЗ перед всеми тестами этого файла.
        // Здесь можно подключить нужные классы или создать заглушки.
        require_once SOURCES . '/my_class.php';
    },

    'tests' => [
        
        'простое сложение' => function ( ) {
            $res = 2 + 2;
            // Assert — класс для проверок
            Assert::same( 4 , $res , 'Два плюс два должно быть четыре' );
        },

        'проверка строки' => function ( ) {
            $str = 'Hello World';
            Assert::contains( 'World' , $str );
            Assert::notContains( 'Python' , $str );
        }

    ],
];
```

## Доступные ассерты (Assert)

Класс `Assert` предоставляет следующие методы (при провале бросают `AssertException`):

*   `Assert::true( $value )` — проверяет, что значение строго `true`.
*   `Assert::false( $value )` — проверяет, что значение строго `false`.
*   `Assert::same( $expected, $actual )` — строгое сравнение (`===`).
*   `Assert::eq( $expected, $actual )` — нестрогое сравнение (`==`).
*   `Assert::null( $value )` — проверяет на `null`.
*   `Assert::contains( $needle, $haystack )` — проверяет вхождение подстроки.
*   `Assert::instance( $className, $object )` — проверяет, является ли объект экземпляром класса.
*   `Assert::count( $expected, $array )` — проверяет количество элементов в массиве.

## Запуск

Откройте в браузере: `https://<ваш_домен>/tests/`

Вы увидите дашборд со списком всех ваших модулей. 
Зеленые галочки означают, что тесты прошли. Красные крестики и текст ошибки появятся, если ассерт провалился.
