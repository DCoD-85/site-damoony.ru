# 💻 Ядро: Базовые классы

Каждая страница в SimplCMS — это PHP-класс, который наследуется от базового класса `algoritm_`. 
Базовый класс берет на себя рутину: проверку авторизации, обработку AJAX-запросов и вызов нужного метода.

## Класс `main` (Оркестратор)
Объект `$this->main` доступен внутри любого класса страницы. Это главный контейнер, который хранит в себе всё необходимое:
*   `$this->main->alliasglobal` — глобальные блоки (header, footer, sidebar).
*   `$this->main->dataprovider` — доступ к базе данных.
*   `$this->main->user` — информация о текущем пользователе (гость или авторизован).
*   `$this->main->library` — утилиты для работы с URL и ссылками.

## Класс `algoritm_` (Базовый класс страницы)
Когда роутер `tree.php` находит нужный файл страницы, он создает объект этого класса и вызывает метод `default()`.

Внутри `algoritm_` срабатывает следующая цепочка вызовов:

1. **`default()`** — главная точка входа.
2. Если запрос пришел через AJAX (JS), вызывается **`ajax()`**.
   *   Если пользователь гость ➔ **`ajax_guest()`**
   *   Если авторизован ➔ **`ajax_logged()`**
3. Если это обычный запрос (браузер), вызывается **`role()`**.
   *   Если пользователь гость ➔ **`guest()`**
   *   Если авторизован ➔ **`logged()`**

По умолчанию все эти методы пустые и возвращают `false`.

## Пример переопределения
Вам не нужно переопределять `default()`, если вы хотите просто разделить логику для гостей и авторизованных.

```php
<?PHP

namespace damoony_ru\www;

class algoritm_lang_profile extends \algoritm_ {

    // Этот метод сработает, только если пользователь НЕ авторизован
    public function guest() {
        $vt = new \visuotag();
        $vt->tag('h1')->content('Пожалуйста, войдите в систему');
        $this->main->alliasglobal->center->section_add('auth_msg', $vt);
        
        return true;
    }

    // Этот метод сработает, если пользователь УСПЕШНО авторизован
    public function logged() {
        $username = $this->main->user->login(); // получаем логин из сессии
        
        $vt = new \visuotag();
        $vt->tag('h1')->content('Профиль пользователя: ' . $username);
        $this->main->alliasglobal->center->section_add('profile', $vt);
        
        return true;
    }
}
```

## Возвращаемые значения (Контракт)
Метод, который вы вызываете (`guest`, `logged`, `default`), **обязан вернуть `true`**.
*   Если метод вернул `true` — роутер считает, что страница успешно отрисована, и отдает HTML.
*   Если метод вернул `false` — роутер прерывает работу и отдает страницу `errors/404.php`.
*   Если нужно сделать редирект, используйте `header('Location: ...'); exit;` прямо внутри метода.
