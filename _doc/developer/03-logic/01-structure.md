# 💻 Логика: Структура папок (Домен и Аллиас)

Бизнес-логика проекта находится в папке `app/`. Чтобы избежать путаницы, структура строго иерархична: 
`app / <версия_движка> / domain / <real_домен> / ...`

## Уровни вложенности

### 1. Уровень Домена (`domain/damoony.ru/`)
Здесь хранятся данные, которые **общие для всех аллиасов** этого домена.
*   **`dataprovider.php`** — фасад для доступа к базе данных домена.
*   **`alliasglobal.php`** — класс-менеджер глобальных блоков.
*   **`alliasscheme.php`** — класс-менеджер схем (layout).
*   **Папка `alliasglobal/`** — физические файлы блоков (`top`, `left`, `center`, `right`, `bottom`).
*   **Папка `alliasscheme/`** — физические файлы схем.

### 2. Уровень Аллиаса (`domain/damoony.ru/allias/www/`)
Здесь хранится уникальная логика для конкретного поддомена (например, `www` или `visuo`).
*   **Папка `algoritm/`** — деревья страниц, логика URL, файлы `.rules.json`.
*   **Папка `dataprovider/`** — специфичные провайдеры данных (если аллиасу нужны свои методы работы с БД).
*   **`helpers.php`** — вспомогательные функции (например, генерация меню).
*   **`include.php`** — файл инициализации аллиаса (подключение хелперов и роутинга).

## Пример правильной структуры

Ниже приведен эталонный пример для домена `damoony.ru` и аллиаса `www`.

```text
app/
└── alpha.0.0/
    └── domain/
        └── damoony.ru/
            ├── allias.php                 # Управление аллиасами
            ├── alliasglobal.php           # Управление блоками
            ├── alliasscheme.php           # Управление схемами
            ├── dataprovider.php           # Главный провайдер БД
            │
            ├── alliasglobal/              # Общие блоки домена
            │   ├── top/top.php
            │   ├── center/center.php
            │   └── bottom/bottom.php
            │
            ├── alliasscheme/              # Общие схемы домена
            │   ├── alliasscheme_www.php
            │   └── alliasscheme_error.php
            │
            └── allias/
                └── www/                   # Конкретный аллиас
                    ├── algoritm/          # ★ Страницы и URL
                    │   ├── algoritm.php
                    │   ├── algoritm.rules.json
                    │   └── lang/          # /ru-ru, /en-en и т.д.
                    │
                    ├── dataprovider/      # Локальный провайдер (если нужен)
                    ├── helpers.php        # Функции аллиаса
                    └── include.php        # Инициализация
```

## Важное правило
Если вам нужно создать блок (например, `sidebar`), который будет использоваться только на аллиасе `visuo`, но не нужен на `www`, вы можете создать его локально. Но по умолчанию мы придерживаемся подхода: **все блоки лежат в `alliasglobal/`** (единый источник правды), так как это упрощает кэширование и переиспользование.
