A. alliasglobalscript.php
================================================================
namespace: damoony
abstract class alliasglobalscript

РОЛЬ:
  База для не-визуальных скриптов: headers, head.
  Не имеет visuotag, не отдаётся в слоты.
  Работает с meta, куками, заголовками.

СВОЙСТВА
  alliasglobal : alliasglobal
  main         : main
  script_name  : string   — имя скрипта
  run_done     : bool     — защита от повторного run()

МЕТОДЫ
  __construct( alliasglobal )  → init()
  init()                       — hook (переопределяется потомком)
  run()                        — применение (вызывается из main::release)
  script_name() : string       — аксессор

ПОТОК
  main::release()
    foreach alliasglobal->scripts as script:
      script->run()

ВАЖНО:
  - init() безопасен для редиректов (заголовки ещё не отправлены).
  - run_done защищает от повторного run (main::release может быть
    вызван несколько раз).

B. alliasglobal_filler_trait.php
================================================================
namespace: damoony
trait alliasglobal_filler_trait

РОЛЬ:
  Даёт классам filler'ов API show/hide/is_enabled.
  Свойство $enabled объявлено в трейте.

СВОЙСТВА
  enabled : bool = true

МЕТОДЫ
  show()       : static  — enabled = true
  hide()       : static  — enabled = false
  is_enabled() : bool

ЗАМЕЧАНИЯ
  - Файл переехал из корня домена в alliasglobal/ (git: rename).
  - Класс filler'а должен подключить трейт и НЕ объявлять
    $enabled повторно — иначе конфликт свойств.
