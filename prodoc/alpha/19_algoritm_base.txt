================================================================
19_ALGORITM_BASE — algoritm_.php + algoritmdata_.php
Роутинг-фреймворк алгоритмов.
================================================================

ФАЙЛЫ ВНЕ namespace (глобальные классы):
  algoritm_       — базовый алгоритм (роутер)
  algoritmdata_   — контейнер параметров роутинга

================================================================
A. algoritmdata_.php
================================================================
namespace: (глобальный)

СВОЙСТВА
  available : array   — список разрешённых сегментов URL
  auth      : bool    — требуется авторизация
  search    : bool    — разбирать ли URL через regex
  default   : bool    — вызвать default(), если URL пуст

МЕТОДЫ
  set($available, $auth, $search, $default)  — установить всё
  get_available() / get_auth() / get_search() / get_default()

РОЛЬ: контейнер. Никакой логики — просто пакет параметров.

================================================================
B. algoritm_.php
================================================================
namespace: (глобальный)

РОЛЬ:
  Базовый класс для всех алгоритмов — как корневых (visuo/algoritm/algoritm.php),
  так и страничных (algoritm_lang_index.php и т.п.).
  Реализует роутинг по URL: сегмент → класс → include → new → algoritm() → release().

СВОЙСТВА (ключевые)
  main                     : main
  algoritm                 : ?algoritm_     — родитель (для вложенных)
  args                     : array          — regex-группы из URL
  algoritmdata             : ?algoritmdata_
  path                     : string

  # пути и классы (переопределяются в потомках)
  basepath / baseclass     — куда include'ить обычные страницы
  errorpath / errorclass   — error-algoritm
  authpath / authclass     — auth-algoritm
  algoritm_classes         : array          — созданные экземпляры по позиции URL

  # page settings (override)
  logged                   : bool
  available                : array
  auth                     : bool
  search                   : bool
  default                  : bool

МЕТОДЫ — фреймворк
----------------------------------------------------------------

__construct( main , array $args = [] )
    Привязка $main, $args.
    $this->algoritm = $main->algoritm (родитель).
    $this->algoritmdata = new algoritmdata_().

args( array $args )
    Установить args вручную.

logic( )
    CORS-политика: собирает список разрешённых origin'ов
    (домены + их аллиасы по http/https), и если HTTP_ORIGIN
    в списке — отправляет Access-Control-Allow-*.

release( )
    algoritmdata->set($this->available, $this->auth, $this->search, $this->default)
    release_($this)

release_( object $object )
    Алгоритм роутинга:
      $auth = $object->algoritmdata->auth
      if $auth:
        $auth = auth()   — реальная проверка
      else $auth = true
      if $auth:
        if !$search && $default:
          $object->default() ? true : error_($object)
        else:
          include_ext($object, $available, $search, $default)

include_ext( object $object , $available , $search , $default )
    ГЛАВНЫЙ РОУТЕР.

    1. Позиция в URL:
         $url_base_pos = count(explode('_', get_class($object))) - 1
         Для alliasglobal_top_visuo → 3 (глубина вложенности классов).
       URL-сегмент: $url_base_real[$url_base_pos]
       Если не существует — ''.

    2. Если $search:
         foreach $available:
           Формат элемента: 'regex|slug'
             mb_ereg('^' . regex . '$', $url_base_real[pos], $matches)
             При совпадении:
               $args[$matches[1] ?? ''] = $matches[2] ?? ''
               $available[key] = slug
               break
           Простое значение — сравнение equality.

    3. $in_array = in_array($url_base_real[pos], $available) ? значение : false

    4. Обновление basepath/baseclass родителя:
         $main->algoritm->basepath .= url_segment . DS
         $main->algoritm->baseclass .= '_' . url_segment

    5. $path = basepath . baseclass . '.php'
       $class = \ns\allias\baseclass

       on_route($class, $path)   — hook

    6. Если $in_array && include_once $path:
         if class_exists:
           new $class($main, $args)
           проверка $logged:
             false → algoritm() + release()
             true  → main->is_guest() ? алгоритм : error_()

    7. Если класс не существует:
         http_response_code(403)
         algoritm_classes[pos-1]->release()

    8. Если $in_array пустой:
         if object->algoritmdata->default === true:
           object->default() ? true : error_(object)
         else:
           include errorclass
           new errorclass → algoritm() → release()

auth( )
    Проверка авторизации:
      if !main->is_guest() → true
      else:
        include authclass
        new authclass($main, [])
        authclass->algoritm()
        authclass->release()
      (ничего не возвращает — либо true, либо сайд-эффект от auth-класса)

error_( object $object )
    Аварийный рендер:
      - Очистка center: $center->visuotag()->clear()
      - include errorclass
      - new + algoritm() + release()

HELPERS
  is_ajax()    → $main->render->getdata('render_ajax')
  is_guest()   → $main->is_guest()
  is_post()    → !empty($_POST)
  is_default() → URL-сегмент на позиции класса === ''
                 (позиция считается по подчёркиваниям в get_class)

STUBS (переопределяются в потомках)
  algoritm() / guest() / logged() / ajax_guest() / ajax_logged()
  default() / ajax() / role()
  on_route($class, $path)
  clear() / debug()

ЗАМЕЧАНИЯ
----------------------------------------------------------------
1. Именование с подчёркиванием: get_class → explode('_').
   Если в классе больше подчёркиваний, чем глубина URL —
   позиция не совпадёт. Хрупкая эвристика.
2. include_once $path — если файл уже был подключён,
   вернёт true → «пройдёт», но new создаст второй экземпляр.
3. auth() без return true/false в явном виде — фактически void.
   release_() проверяет if ($auth) но auth() возвращает null
   при инициализированном $auth=false. На деле $auth = null,
   ветка if ($auth) не срабатывает.
   Это баг: при $auth=true и госте — release пойдёт дальше
   без явного «отказать». Спасение — authclass сам делает что-то
   (redirect/exit).
4. error_() — clear() у center, потом include. Если center
   ещё не отрендерен — ок. Если уже — контент стирается.
5. basepath/baseclass мутируют $main->algoritm — состояние роутера
   живёт между вызовами. Отладка будет путаться.
