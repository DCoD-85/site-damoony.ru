================================================================
A. www/constants.php
================================================================

РОЛЬ: только define() — никакой логики, никаких функций.

КОНСТАНТЫ
----------------------------------------------------------------
  DS, DSA                    — дублируют то, что уже есть в index.php
                               (страховка на случай прямого include).
                               DS = DIRECTORY_SEPARATOR
                               DSA = '/'

  GL_LOG       = false       — флаг логирования
  GL_DEBUG     = false       — общий debug
  GL_DEBUGHARD = false       — усиленный debug (вероятно, доп. вывод)
                               Все три: по умолчанию выключены.
                               Проверяются через defined() — можно
                               переопределить ДО этого файла.

  DB_LIMIT_ONE  = 1          — лимит "одна запись"
  DB_LIMIT_PAGE = 10         — лимит на страницу
  DB_LIMIT_MAX  = 1000       — жёсткий максимум
                               Комментарий в шапке намекает, что
                               эти значения могут быть переопределены
                               через GET/POST до DB_LIMIT_MAX (механизм
                               в самом файле отсутствует — где-то
                               выше/ниже по коду).

  VISUOLINK_RAND_DEFAULT = true
                             — дефолт для параметра rand в visuolink
                               (добавлять ?rand= к URL для сброса кэша).

ЗАМЕЧАНИЯ
----------------------------------------------------------------
- Файл — плоский список define. Ничего не делает, кроме констант.
- Все define обёрнуты в if ( ! defined( ... ) ) — идемпотентно.
- DS/DSA дублируются в трёх местах: index.php, included.php,
  constants.php. Безвредно, но можно оставить только здесь.

================================================================
B. www/included.php
================================================================

РОЛЬ: маленькая библиотека include'ов и «красивого» die().
      Подключается ПОСЛЕ constants, ДО main.

ФУНКЦИИ
----------------------------------------------------------------

fo( array $fo , $file_sep_start = ' [ ' , $file_sep_end = ' ] ' ) : string
    Форматирует триплет [ file , line , method ] в строку
    для сообщений об ошибке.
    Пример: fo([__FILE__, __LINE__, __METHOD__])
            → 'method [ file:line ]'

bad( array $fo , $title = 'Ошибка' , $message = 'Ошибка' ) : never
    Аварийный die() с HTML-страницей.
    Выводит: title, message, file:line, ссылку mailto.
    Есть закомментированная ветка рендера через visuotag —
    на будущее (когда visuo уже загружен, можно рендерить красиво).

include_bad( array $fo , string $file ) : never
    Обёртка bad() с фиксированным текстом «Не возможно подключить файл».

include_my( array $fo , string $file ) : void
    include_once $file; если не вышло — include_bad().
    Обёртка для «строгого» include.

include_array( array $fo , array $files , array $classes = [] , string $release_path = '' ) : void
    Пакетное подключение:
      1. foreach $files → include_my()
      2. если $files пуст → bad() «Отсутствуют файлы для подключения»
      3. если $classes задан → проверяет class_exists() каждого,
         собирает отсутствующие и выдаёт bad() со списком.
    Параметр $release_path объявлен, но не используется — мёртвый.

ЗАМЕЧАНИЯ
----------------------------------------------------------------
- Файл определяет DS/DSA повторно — избыточно (см. constants.php).
- Стиль: табы, компактно, без комментариев на русском — ранний код.
- bad() НЕ экранирует $title/$message/$file — если туда попадёт
  пользовательский ввод, будет XSS. Сейчас всё приходит из кода.
- include_array() — ранний механизм, местами вытеснен error_file()
  из index.php. Сосуществуют.
